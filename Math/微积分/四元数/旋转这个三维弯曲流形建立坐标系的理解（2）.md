### 第一步：找原点 —— $W$ 轴（实轴）的诞生

我们规定战斗机停在跑道上，机头正北，机翼保持绝对水平。
此时，**三个欧拉角（Roll滚转, Pitch俯仰, Yaw偏航）全部等于 $0^\circ$**。
这就是我们整个系统的**“绝对标准姿态（Identity Pose）”**。

它在这个四维数学宇宙里，应该放在哪里？
根据四元数公式：$q = \cos(\theta/2) + \sin(\theta/2)(x\mathbf{i} + y\mathbf{j} + z\mathbf{k})$。
既然没有任何旋转（$\theta = 0^\circ$）：
$q = \cos(0) + \dots = 1 + 0\mathbf{i} + 0\mathbf{j} + 0\mathbf{k}$。

**结论 1（你的第一个坐标轴）：**
当欧拉角全部为 0 时，战斗机的姿态点位于四维空间的** $(1, 0, 0, 0)$**。
这就是四维宇宙的正北极！**这根轴，就是四元数的实数轴（$W$ 轴）。** 它代表着“绝对静止、无任何旋转的本体”。

### 第二步：找另外三根轴 —— $X, Y, Z$ 虚轴在哪？

在大炮的例子里，你让角度转了 $90^\circ$（走到赤道），找到了 $(0,1,0)$ 和 $(0,0,1)$。

但是在战斗机的四维空间里，**你转 $90^\circ$ 是找不到坐标轴的！**
还记得四元数里面藏着一个变态的 **“半角公式（$\theta / 2$）”** 吗？
如果要在四维坐标系里，让实部 $W$ 变成 $0$（也就是走到四维空间的“赤道”上），你必须让 $\cos(\theta / 2) = 0$。
这意味着，$\theta/2$ 必须等于 $90^\circ$。
也就是说，**战斗机在物理世界里必须转足足 $180^\circ$！**

现在，我们按照这个法则，去寻找剩余的三根轴：

**1. 寻找 $X$ 虚轴： $(0, 1, 0, 0)$**
*   **物理动作：** 战斗机仅仅绕着自己的纵轴（机头到机尾），狠狠地**滚转（Roll）了 $180^\circ$**！此时机腹朝上（倒飞），俯仰和偏航为 $0$。
*   **代数结果：** $\cos(90^\circ) + \sin(90^\circ)(1\mathbf{i} + 0\mathbf{j} + 0\mathbf{k}) = 0 + 1\mathbf{i} + 0\mathbf{j} + 0\mathbf{k}$。
*   **几何意义：** 战斗机的姿态点，从四维空间的北极 $(1,0,0,0)$，沿着一条大圆弧滑行，刚好滑到了赤道上的 **$(0, 1, 0, 0)$** 点。**这就是第一根虚轴！**

**2. 寻找 $Y$ 虚轴： $(0, 0, 1, 0)$**
*   **物理动作：** 战斗机不滚转，不偏航，只绕着自己的横轴（左翼到右翼），狠狠地**拉大仰角（Pitch），直到向后翻转 $180^\circ$**，变成机头朝后的平飞状态。
*   **代数结果：** 同样因为半角，变成 $0 + 0\mathbf{i} + 1\mathbf{j} + 0\mathbf{k}$。
*   **几何意义：** 战斗机姿态点滑到了赤道上的另一个致盲点 **$(0, 0, 1, 0)$**。**这就是第二根虚轴！**

**3. 寻找 $Z$ 虚轴： $(0, 0, 0, 1)$**
*   **物理动作：** 战斗机像直升机一样，平平地原地**掉头（Yaw）了 $180^\circ$**。
*   **代数结果：** $0 + 0\mathbf{i} + 0\mathbf{j} + 1\mathbf{k}$。
*   **几何意义：** 战斗机姿态点滑到了最后那根与前面所有轴都垂直的赤道标杆 **$(0, 0, 0, 1)$**。**这就是第三根虚轴！**
