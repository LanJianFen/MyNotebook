### 第一步：求出“四元数 3”（即相对过渡四元数 $\Delta q$）

假设：
*   **当前姿态 1（起始）：** $q_1 = (w_1, x_1, y_1, z_1)$
*   **目标姿态 2（终点）：** $q_2 = (w_2, x_2, y_2, z_2)$

我们想找到一个“旋转动作”——也就是**四元数 3（记作 $\Delta q$）**。
它的物理意义是：**把 $\Delta q$ 作用在 $q_1$ 上，就能变成 $q_2$**。

用数学公式表达就是：
$$q_2 = \Delta q \otimes q_1$$
*(注意：这是单边乘法，因为我们是在更新摄影机/本体姿态，没有用夹心！)*

为了求出 $\Delta q$，我们在等式两边同时**右乘** $q_1$ 的逆（$q_1^{-1}$）：
$$\Delta q = q_2 \otimes q_1^{-1}$$

因为我们的姿态四元数都是“归一化”的（长度为1），在四元数宇宙里，**单位四元数的逆，直接等于它的共轭（Conjugate，即虚部取反）**。
所以，**最核心的计算公式诞生了：**
$$\Delta q = q_2 \otimes q_1^*$$
即：$\Delta q = (w_2, x_2, y_2, z_2) \otimes (w_1, -x_1, -y_1, -z_1)$

*(这就是你想要的“四元数 3”。底层代码只要跑一遍四元数乘法展开，就能瞬间算出这个 $\Delta q$ 的 $w_3, x_3, y_3, z_3$)*。

### 第二步：扒开“四元数 3”，提取真正的物理转轴和角度

现在我们拿到了四元数 3：$\Delta q = (w_3, x_3, y_3, z_3)$。
你刚才说：“绕着这个四元数 3 的轴做旋转”。**这绝对是大师级的物理直觉！**

怎么把这个“轴”和“角度”从 $\Delta q$ 的肚子里剖出来呢？利用我们之前说的“半角公式”：

1.  **提取真正的旋转角度 $\alpha$：**
    因为 $w_3 = \cos(\alpha / 2)$
    所以，物理世界中飞机需要转动的绝对真实角度是：
    $$\alpha = 2 \arccos(w_3)$$

2.  **提取真正的旋转轴 $\vec{u}$：**
    因为虚部 $(x_3, y_3, z_3) = \vec{u} \cdot \sin(\alpha / 2)$
    所以，这根插在三维空间里的真实转轴（单位向量）是：
    $$\vec{u} = \frac{(x_3, y_3, z_3)}{\sin(\alpha / 2)} = \frac{(x_3, y_3, z_3)}{\sqrt{1 - w_3^2}}$$

**【物理意义核爆点】：**
无论姿态 1 和姿态 2 在三维空间里差得有多离谱（比如机头朝南又肚皮朝上，要转成机头朝东且平飞）。
通过 $\Delta q = q_2 \otimes q_1^*$ 算出来的这根轴 $\vec{u}$ 和角度 $\alpha$，代表着**全宇宙中最短、最直接、最平滑的那条物理捷径**！这就是大名鼎鼎的**欧拉主轴旋转定理**！

### 第三步：怎么“平滑地”转过去？（球面线性插值 SLERP）

在实际工程中，飞机不可能瞬间“瞬移”到目标姿态 2，它需要随着时间 $t$（比如 $t$ 从 0 秒走到 1 秒），一帧一帧地转过去。

既然我们已经有了总动作 $\Delta q$，我们只需要按比例把这个动作“切碎”。
如果总角度是 $\alpha$，那走了一半时，角度就是 $\alpha \times 0.5$。

在四维超球面（李群 $S^3$）上，这个平滑走大圆的终极插值公式（SLERP）写为：
$$q(t) = \frac{\sin((1-t)\Omega)}{\sin(\Omega)} q_1 + \frac{\sin(t\Omega)}{\sin(\Omega)} q_2$$
*(其中 $\Omega$ 是 $q_1$ 和 $q_2$ 在四维空间里的夹角，$\cos\Omega = q_1 \cdot q_2$。$t$ 是 0 到 1 之间的时间进度)*。

或者用你算出的“四元数 3（$\Delta q$）”来写，最纯粹的代数形式是：
$$q(t) = (\Delta q)^t \otimes q_1$$
*(注：这就是让旋转动作 $\Delta q$ 随着时间 $t$ 逐渐生效，当 $t=0$ 时是 $q_1$，当 $t=1$ 时完美达到 $q_2$)*。
