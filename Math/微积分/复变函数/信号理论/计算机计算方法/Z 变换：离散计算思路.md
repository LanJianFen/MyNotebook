

这个问题的逻辑极其犀利！你直接抓住了从“数学理论”走向“计算机落地”的核心矛盾。

我们顺着你的认知框架来对比：
* **时域连续，频域连续（无限）：** CFT / Laplace $\implies$ 计算机算不了。
* **时域离散（无限），频域连续：** DTFT / Z 变换 $\implies$ 计算机依然算不了！因为**时域要加到无穷大，频域是一整张连续的复平面**。

为了让计算机能够真正执行计算，我们必须在 **时域** 和 **变换域（Z 域）** 各狠狠地“切一刀”（离散化 + 截断）！

工程和数学上，对 Z 变换的处理分成了**三条极其明确的落地路线**：

---

### 路线一：退守单位圆并均匀扎针 $\implies$ 蜕变为 DFT / FFT（最常用）

既然计算机算不了一整张连续的 Z 平面，最直接的想法就是：**我不看整张平面了，我只看最重要的单位圆（频响），并且在单位圆上等间隔采 $N$ 个点！**

#### 计算机做的两刀处理：
1. **时域切一刀（截断）：** 只取前 $N$ 个采样点 $n = 0, 1, \dots, N-1$。
2. **Z 域切一刀（单位圆等分扎针）：**
   把连续复变量 $z$ 限制在单位圆上，并等间隔取 $N$ 个离散点：
   $$ z_k = e^{j \frac{2\pi}{N} k} \quad (k = 0, 1, \dots, N-1) $$

代入 Z 变换公式：
$$ X(z_k) = \sum_{n=0}^{N-1} x[n] z_k^{-n} = \sum_{n=0}^{N-1} x[n] e^{-j \frac{2\pi}{N} k n} = \mathbf{X_{\text{DFT}}[k]} $$

> **结论：** 对 Z 变换在单位圆上做离散化采样的产物，**就是 DFT！** 计算机随后就可以用 **FFT（快速傅里叶变换）** 在 $O(N \log N)$ 的极速下把它算出来。

---

### 路线二：不限于单位圆，在复平面螺旋线上扎针 $\implies$ Chirp Z 变换 (CZT)

如果你跟计算机说：“我不想看单位圆，我想看系统在某个衰减圆周上的特性（比如极点附近），或者我想把某个极窄的频段放大 100 倍看，能不能算？”

**能！这就是前面提到的 Chirp Z 变换（CZT）。**

#### 计算机的处理：
在 Z 平面上定义一条离散的等角螺旋采样轨迹：
$$ z_k = A \cdot W^{-k} \quad (k = 0, 1, \dots, M-1) $$
* $A = A_0 e^{j\theta_0}$：采样的**起始半径和起始角度**（可以在复平面任意位置）；
* $W = W_0 e^{-j\phi_0}$：采样的**向外/向内螺旋伸缩率与旋转步长**。

计算机通过代数技巧（Bluestein 算法），把这种任意复平面的 Z 变换采样**巧妙转化成卷积，再用 FFT 极速算出**！
* **应用：** 频谱局部超高精度放大（Zoom-FFT）、窄带雷达目标检测。

---

### 路线三：根本不算复数值，把 $Z$ 当作代数多项式 $\implies$ 差分方程代码化（控制与滤波）

这是计算机处理 Z 变换最惊艳、也是工程中使用最广的路线——**“化整为零，不求变换值，只求差分递推！”**

在单片机、DSP 芯片、无人机飞控代码里，计算机**根本不去计算 $X(z)$ 的复数积分或点集**，而是利用时移性质 $z^{-1}$，把 Z 域的传递函数直接**还原成 C 语言代码**！

#### 计算机的处理流程：
假设我们在理论上设计好了一个最优滤波器的 Z 变换传递函数：
$$ H(z) = \frac{Y(z)}{X(z)} = \frac{b_0 + b_1 z^{-1}}{1 - a_1 z^{-1}} $$

1. **交叉相乘（初中代数）：**
   $$ Y(z)(1 - a_1 z^{-1}) = X(z)(b_0 + b_1 z^{-1}) $$
   $$ Y(z) - a_1 z^{-1} Y(z) = b_0 X(z) + b_1 z^{-1} X(z) $$

2. **时移性质逆映射（$z^{-1} \implies$ 延迟一个采样点）：**
   $$ y[n] - a_1 y[n-1] = b_0 x[n] + b_1 x[n-1] $$

3. **移项，写成计算机每毫秒执行一次的代码（Direct Form）：**
   $$ \mathbf{y[n] = a_1 y[n-1] + b_0 x[n] + b_1 x[n-1]} $$

```c
// 嵌入式芯片里的真实滤波函数（Z 变换的工程终极形态）
float IIR_Filter(float x) {
    static float x_last = 0.0f; // 对应 X(z) * z^-1
    static float y_last = 0.0f; // 对应 Y(z) * z^-1
    
    // 这行代码就是 Z 变换传递函数的物理化身！
    float y = a1 * y_last + b0 * x + b1 * x_last;
    
    // 更新状态寄存器
    x_last = x;
    y_last = y;
    return y;
}
```

---

### 终极全景总结

面对连续不可算的 Z 变换，计算机的世界分化出了三条大道：

1. **如果你要看信号的频率成分（频谱分析）：**
   $\implies$ 限制在单位圆上采样 $\implies$ **转化为 DFT / FFT**。
2. **如果你要看复平面局部精细结构（高分辨率分析）：**
   $\implies$ 沿指定复平面弧线采样 $\implies$ **转化为 CZT（Chirp Z 变换）**。
3. **如果你要对信号进行实时滤波/控制系统设计（系统实现）：**
   $\implies$ 利用 $z^{-1}$ 映射回差分方程 $\implies$ **转化为 C/C++ 递推算法代码**。
