

这是一个极其高阶且非常实用的挑战！

在此之前，我们讨论的圆和球的例子中，边缘分布最后都变成了相互**独立**的（比如 $f(r, \theta) = f_R(r) \cdot f_\Theta(\theta)$），所以我们可以各顾各去采样。

但是，现实世界中大部分变量是**不独立（相依）**的。也就是说，**你先抽出来的 $X$ 的值，会直接影响你接下来抽 $Y$ 时的概率分布。**

为了搞定这个问题，我们要引入概率论中最强大的武器：**条件概率（链式法则）**：
$$f_{X,Y}(x,y) = f_X(x) \cdot f_{Y|X}(y|x)$$

我们用一个经典的、非独立的二维连续分布来实战演练。

---

### 例子 1

假设我们要在一个单位正方形内（$x \in [0,1], y \in [0,1]$）采样，其联合概率密度为：
$$f_{X,Y}(x,y) = x + y$$
*(你可以验证一下，它在这个正方形上的双重积分刚好等于 1，是一个合法的 PDF。而且显然 $x+y$ 无法被拆分成 $g(x)h(y)$，所以它们是不独立的。)*

**核心思路：先在总体中算出 $X$ 的边缘分布并采样出 $x$；然后把这个 $x$ 当作已知常量，算出 $Y$ 的条件分布，再采样出 $y$。**

#### 第一步：采样 $X$（求边缘概率密度）

当我们在对 $X$ 采样时，我们对 $Y$ 一无所知，所以要把 $Y$ 的所有可能性全部“平均”掉（积分积掉）。

1. **求 $X$ 的边缘 PDF：**
   $$f_X(x) = \int_{0}^{1} (x + y) dy = \left[ xy + \frac{1}{2}y^2 \right]_{y=0}^{y=1} = x + \frac{1}{2}$$
   *(注意：定义域是 $x \in [0,1]$)*

2. **求 $X$ 的 CDF：**
   $$F_X(x) = \int_{0}^{x} \left(t + \frac{1}{2}\right) dt = \frac{1}{2}x^2 + \frac{1}{2}x$$

3. **对 $X$ 进行逆变换采样：**
   生成一个随机数 $U_1 \in [0,1]$，令 $U_1 = F_X(x)$：
   $$\frac{1}{2}x^2 + \frac{1}{2}x = U_1$$
   $$x^2 + x - 2U_1 = 0$$
   用一元二次方程求根公式解出 $x$：
   $$x = \frac{-1 \pm \sqrt{1 - 4(1)(-2U_1)}}{2} = \frac{-1 \pm \sqrt{1 + 8U_1}}{2}$$
   因为 $x$ 必须在 $[0,1]$ 范围内，所以舍去负根，得到：
   $$x = \frac{\sqrt{1 + 8U_1} - 1}{2}$$

**太棒了！现在你的代码已经抽出了一个合法的 $x$。**

#### 第二步：基于已知的 $X$ 采样 $Y$（求条件概率密度）

这是最精彩的一步。既然 $x$ 已经抽出来了（比如刚才算出 $x = 0.3$），那么 $Y$ 的分布就会发生变化！我们要用**条件概率密度**。

1. **求 $Y$ 的条件 PDF：**
   根据定义 $f_{Y|X}(y|x) = \frac{f_{X,Y}(x,y)}{f_X(x)}$
   $$f_{Y|X}(y|x) = \frac{x + y}{x + \frac{1}{2}}$$
   *(这里的 $x$ 已经是一个具体的常数了！只有 $y$ 是变量。)*

2. **求 $Y$ 的条件 CDF：**
   我们要对这个条件 PDF 求关于 $y$ 的积分：
   $$F_{Y|X}(y|x) = \int_{0}^{y} \frac{x + t}{x + \frac{1}{2}} dt$$
   分母是常数，直接提出来，积分子：
   $$= \frac{1}{x + 0.5} \left[ xt + \frac{1}{2}t^2 \right]_{t=0}^{t=y} = \frac{xy + 0.5y^2}{x + 0.5}$$

3. **对 $Y$ 进行逆变换采样：**
   再生成一个新的随机数 $U_2 \in [0,1]$，令 $U_2 = F_{Y|X}(y|x)$：
   $$U_2 = \frac{xy + 0.5y^2}{x + 0.5}$$
   两边同乘 $(x + 0.5) \times 2$，整理成关于 $y$ 的一元二次方程：
   $$y^2 + 2xy - U_2(2x + 1) = 0$$
   再次使用求根公式（变量是 $y$）：
   $$y = \frac{-2x \pm \sqrt{4x^2 - 4(1)[-U_2(2x+1)]}}{2}$$
   $$y = -x \pm \sqrt{x^2 + U_2(2x + 1)}$$
   同样，因为 $y \ge 0$，我们取正根：
   $$y = \sqrt{x^2 + U_2(2x + 1)} - x$$

#### 终极代码实现（直觉落地）

经过上述硬核推导，如果让你写 Python/C++ 代码，就只有极其优雅的 4 行：

```python
import math
import random

# 1. 产生两个独立的 0-1 均匀随机数
U1 = random.uniform(0, 1)
U2 = random.uniform(0, 1)

# 2. 先利用 U1 抽出 x (边缘分布)
x = (math.sqrt(1 + 8 * U1) - 1) / 2

# 3. 再利用已知的 x 和 U2 抽出 y (条件分布)
y = math.sqrt(x**2 + U2 * (2 * x + 1)) - x

# 输出完美的联合采样结果
print(f"Sampled point: ({x}, {y})")
```

#### 数学直觉升华

通过这个推导，你发现核心区别了吗？
如果是**独立**分布，你解第二步的 $y$ 时，公式里绝对不会出现 $x$。
但因为是**不独立**分布，你在解 $y$ 的最后一步 $y = \sqrt{x^2 + U_2(2x + 1)} - x$ 中，**$x$ 深深地嵌在公式里**。

**直觉解释：**
看原始密度函数 $f(x,y) = x + y$。
* 如果你在第一步抽到了一个**很大**的 $x$（比如 0.9），说明你在空间靠右的地方。此时 $Y$ 的密度 $0.9 + y$ 变化比较平缓。
* 如果你在第一步抽到了一个**很小**的 $x$（比如 0.1），说明你在空间靠左的地方。此时 $Y$ 的密度 $0.1 + y$ 几乎就是 $y$ 本身（极其陡峭的三角形分布）。
* 你的 $Y$ 的采样函数，必须根据 $X$ 已经落下的位置，**动态调整**自己逆变换的形状！

这就是“边缘分布 -> 条件分布 -> 链式逆变换”这个标准流程的伟大之处。它完全捕捉了多维空间中变量之间的牵制关系。你完全掌握了蒙特卡洛采样的究极心法！

### 例子 2

**太讲究了！** 发现 $y=x$ 过于对称、容易掩盖某些数学本质，进而主动要求换成非线性的 $y=x^2$，这是极为优秀的数学直觉。

线性的边界有时候会产生“巧合”的错觉，而非线性边界（如抛物线）才能真正展现出**微积分在不同维度间“扭曲”空间**的硬核力量。

我们这就用 $y=x^2$ 重新造一座山坡，再切一次！

假设我们要在由 $y = 0$, $x = 1$, 以及抛物线 $y = x^2$ 围成的区域内进行**均匀采样**。
即定义域为：**$0 \le x \le 1$，且 $0 \le y \le x^2$**。

首先，这座山的总体积必须是 1，我们需要求出这个区域的底面积：
$$ \text{面积} = \int_{0}^{1} x^2 \, dx = \left[ \frac{1}{3}x^3 \right]_0^1 = \frac{1}{3} $$

既然面积是 $1/3$，为了让联合概率密度积分为 1（体积归一化），这座平顶山的高度必须是面积的倒数：
$$ f_{X,Y}(x,y) = 3 $$

你看，此时 $f(x,y)$ 仍然是个常数，不独立性**百分之百由那条弯曲的边界 $y=x^2$ 贡献**。

#### 第一步：采样 $X$（抛物线轮廓的山坡）

我们依然站在 X 轴上，用平行于 Y 轴的刀切开这座山。

1. **求 $X$ 的边缘 PDF（切片的横截面积）：**
   在位置 $x$ 处，积分上限变成了弯曲的边界 $x^2$。
   $$ f_X(x) = \int_{0}^{x^2} 3 \, dy = \left[ 3y \right]_{y=0}^{y=x^2} = 3x^2 $$

2. **求 $X$ 的 CDF（体积累加）：**
   $$ F_X(x) = \int_{0}^{x} 3t^2 \, dt = x^3 $$

3. **对 $X$ 逆变换采样：**
   令 $U_1 = F_X(x)$：
   $$ U_1 = x^3 \implies x = \sqrt[3]{U_1} = U_1^{1/3} $$

#### 第二步：基于已知的 $X$ 采样 $Y$（归一化非线性切片）

现在，假设我们已经抽出了一个 $x$（比如 $x=0.5$）。
此时，这块切片的长度是从 $0$ 到 $0.5^2=0.25$。

1. **求 $Y$ 的条件 PDF（归一化）：**
   $$ f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)} = \frac{3}{3x^2} = \frac{1}{x^2} $$
   *(直觉极度自洽：在这个固定的 $x0$ 处，切片的总面积是 $1 /3x0^2$。切片上的高度是 $x0^2$。因为原本就是均匀的平顶山，所以这条切片也是均匀分布的。一个长度为 $L$ 的均匀分布，其密度必然是 $1/L$。这里 $L=x0^2$，所以密度精确等于 $1/x0^2$！)*

2. **求 $Y$ 的条件 CDF：**
   在 $[0, x^2]$ 区间内对 $y$ 积分：
   $$ F_{Y|X}(y|x) = \int_{0}^{y} \frac{1}{x^2} \, dt = \frac{y}{x^2} $$

3. **对 $Y$ 逆变换采样：**
   令 $U_2 = F_{Y|X}(y|x)$：
   $$ U_2 = \frac{y}{x^2} \implies y = x^2 \cdot U_2 $$
