

这是一个极其敏锐的提问！你能注意到这个词的**前后顺序和组合**，说明你的底层逻辑思维非常清晰。

在图形学中，**`DepthNormals`（深度+法线）** Pass 是各大游戏引擎为了**极致榨干显卡性能**而发明的一种“捆绑销售”策略。

我们把它拆开，真正吃透它：

---

### 1. `DepthNormals` Pass 到底是干嘛的？

还记得我们前面提过的 `DepthOnly` 吗？它是一张纯黑白的 3D 测距图。

而当车间主任（渲染管线）喊到 ：“**凡是身上带 `DepthNormals` 标签的 Pass 出列！**” 时，这个 Pass 会同时干两件事：
1. **测距（Depth）**：算出这个像素离摄像机有多远。
2. **朝向（Normal）**：算出这个像素所在的面，在世界空间（或观察空间）中是**朝向哪个方向的**（比如朝天、朝左侧、朝右侧）。

最终，这个 Pass 跑完后，引擎会得到一张极其诡异的**花花绿绿的贴图（法线深度图）**。在这张图里，朝上的面可能是绿色的，朝右的面可能是红色的，同时还包含了距离信息。

#### 🛡️ 神级应用场景（为什么要同时知道距离和朝向？）
如果没有这个 Pass，现代几乎所有的 **高品质屏幕后期（Post-Processing）** 都得瘫痪：
*   **SSAO（屏幕空间环境光遮蔽）**：靠它！要想在墙角、物体缝隙处画出真实的阴影死黑，算法必须同时知道：“这两个像素离得近吗？（Depth）” 以及 “这两个像素是互相垂直形成墙角的吗？（Normal）”。
*   **SSR（屏幕空间反射）**：靠它！下雨天的积水想要反射出前方的霓虹灯，光线需要在屏幕上做反射折射计算，必须要知道地面的法线朝向（Normal）和物体的远近（Depth）。
*   **高品质卡通描边（Outline）**：靠它！当一个立方体的两个面深度一样（相连），但朝向（Normal）成 90 度时，立刻在它们之间画一条黑线，完美的硬边缘描边就出来了。

---

### 2. 核心问题：为什么要在 Normal 前面加 Depth？

为什么不叫 `NormalPass`？为什么不叫 `NormalDepth`？
这里面藏着图形学的**三大底层铁律**：

#### 铁律一：没有深度测试，法线就是一锅粥（逻辑绑定）
你想象一下，如果只跑一个纯粹的 `NormalOnly` Pass。
大树挡在大楼前面。大楼的墙面朝南（红色法线），大树的树干朝东（绿色法线）。
如果不先判断出大树离摄像机更近（Depth 测试），显卡怎么知道该把这里的法线画成绿色还是红色？
**深度是法线能正确显示的“前提保护伞”**。先过深度测试，才能留下正确的可见表面法线。

#### 铁律二：老一代 Unity 的“硬核抠门打包法”（历史遗留）
在以前的 Built-in 标准渲染管线时代，手机和电脑的显存非常非常宝贵。
为了省内存，Unity 根本不会生成两张图。它生生搞出了一张 32 位的神仙贴图名叫 `_CameraDepthNormalsTexture`。
它是怎么塞进去的？
*   贴图有 R, G, B, A 四个通道。
*   Unity 把**法线（Normal）的 X 和 Y 压缩进了 R 和 G 通道**。
*   Unity 把**深度（Depth）硬生生切成两半，高八位存进 B 通道，低八位存进 A 通道**。
因为这俩数据被“死死的锁在了同一张贴图里”，不可分割，所以名字也就永远绑在了一起。

#### 铁律三：现代 URP/HDRP 的“顺手羊毛优化”（MRT技术）
在目前的 URP 和 HDRP 管线中，引擎通常会生成两张**独立**的贴图：一张纯深度图（`_CameraDepthTexture`）和一张纯法线图（`_CameraNormalsTexture`）。

那为什么 Pass 名字还是不拆开呢？**因为“顺手”啊！**
在顶点着色器里，算位置坐标（出深度）和算矩阵变换（出法线），都要经历极度昂贵的骨骼动画计算（比如角色身上的 64 根骨头在跳舞）。
如果拆成两个 Pass 跑，等于 64 根骨头要算两遍，手机直接起火。

所以，现代显卡使用了一项叫 **MRT（Multiple Render Targets，多渲染目标）** 的绝技。
车间主任说：“*既然你们反正都要跑一遍极其耗时的骨骼网格顶点运算，而且反正都要算深度，**顺便（同时）**把法线也吐出来给我存进另一张图里吧！*”

### 总结
1. **叫法来源**：它是图形学“极致压榨性能”的产物，代表着它在一个渲染回合内，**同时输出**了屏幕深度和像素朝向。
2. **地位**：只要你的游戏想开 SSAO、想做水面反射、想做高级的屏幕后处理描边，你的 Shader 里就**必须要老老实实地加上这个 `DepthNormals` Pass**，否则你的后期特效测出来的墙面就是平的。
