
这三行代码是 Unity 引擎提供的**全局底层画质与显存优化 API**，用于在切换画质时批量降低场景的面数开销、模型精细度和贴图显存占用 [8, 9, 21]：

```csharp
QualitySettings.lodBias = lodBias;
QualitySettings.maximumLODLevel = maxLODLevel;
QualitySettings.globalTextureMipmapLimit = mipmapLimit;
```

---

#### 1. `QualitySettings.lodBias = lodBias;`
* **中文含义：** **全局模型 LOD 距离偏置（系数）** [8]。
* **作用机制：** 它是控制模型“离相机多远时降级到低模”的乘数 [8]。
  * 默认基准值为 `1.0f` [8]。
  * 设为 `0.5f`（低画质）：原本需要 50 米才切低模的物体，现在在 **25 米处就会提前切到粗糙的低模（LOD1/LOD2）**，大幅压低视野内的同屏总面数和顶点计算量 [8]。
  * 设为 `1.5f`（高画质）：物体在更远的距离依然能保持高清的精模（LOD0）[8]。

---

#### 2. `QualitySettings.maximumLODLevel = maxLODLevel;`
* **中文含义：** **全局最大可用 LOD 截断等级** [9]。
* **作用机制：** 强制限制全场景中“能够渲染的最高精度等级” [9]。
  * 设为 `0`（默认/高画质）：允许正常使用最精细的 `LOD0` [9]。
  * 设为 `1`（低画质）：**引擎会强制放弃所有模型的 `LOD0`**，所有物体最高只能从 `LOD1` 开始显示 [9]。
  * 💡 **省显存神器：** 在开启 Mesh Streaming 时，引擎根本不会把大体积的 `LOD0` 高精网格载入内存和显存，能够立竿见影地防止低端手机闪退（OOM）[9]！

---

#### 3. `QualitySettings.globalTextureMipmapLimit = mipmapLimit;`
* **中文含义：** **全局贴图 Mipmap 分辨率限制（贴图模糊/降级开关）** [21]。
* **作用机制：** 强制全场景的所有贴图在采样时“跳过最高清的几层 Mipmap” [21]。
  * 设为 `0`（默认/高画质）：使用原始尺寸的高清全分辨率贴图（如 2048x2048）[21]。
  * 设为 `1`（中/低画质）：跳过第 0 级，贴图分辨率直接**减半**（2048 变成 1024）。根据面积换算，**能够瞬间立省 75% 的贴图显存和带宽** [21]！
  * 设为 `2`（极低画质）：贴图变为 1/4 尺寸（2048 变成 512），省约 93% 显存 [21]。

### 二、 为什么字符串前面要加 `$` 符号？这是什么语法？

```csharp
Debug.Log($"<color=#00FF7F>[Quality Switch] OK ➔ Shader LOD: {shaderLOD.ToString()}</color>");
```

这个语法叫做 **“字符串插值”（String Interpolation）**，是 C# 6.0 引入的一项核心语法糖 [22, 23]。

#### 1. 前面的 `$` 是什么作用？
`$` 是一个特殊的标记符号，用于告诉 C# 编译器：  
👉 **“接下来的这个双引号字符串是一个【可计算的模板】，请识别里面的 `{}` 大括号，把大括号当成变量或表达式来求值并拼装进去！”** [22, 23]

如果**不加 `$` 符号**，C# 就会把它当成普通文本，输出的结果就会是字面上的 `{shaderLOD.ToString()}`，而不会取出变量里的值：
```csharp
// ❌ 错误（没加 $）：
Debug.Log("LOD 是: {shaderLOD}"); 
// 控制台输出: LOD 是: {shaderLOD}

// ✅ 正确（加了 $）：
Debug.Log($"LOD 是: {shaderLOD}"); 
// 控制台输出: LOD 是: 100
```
