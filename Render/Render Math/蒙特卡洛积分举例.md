

这是一个非常棒的例子！你直接切中了**零方差（Zero Variance）**与**归一化（Normalization）**的核心。

但在给你打满分之前，我们需要修正这中间唯一的一个**“小陷阱”**——关于 PDF 的定义。

让我们一步步演算这个完美的例子：

---

### 1. 第一步：检查 $p(x)$ 合法性（归一化）

**陷阱：** 如果你直接选 $p(x) = x$，它作为一个 PDF 是**不合格**的。
因为 PDF 的总面积（积分）必须是 1（总概率 = 100%）。

我们算一下你选的 $p(x)$ 在 $[0, 1]$ 上的面积：
$$ \int_0^1 x \, dx = \left[ \frac{1}{2}x^2 \right]_0^1 = 0.5 $$

它只有 0.5，不是 1。所以我们必须给它乘个系数（归一化），让它变大一倍。
**正确的完美 PDF 是：**
$$ p(x) = 2x $$
*(验证：$\int_0^1 2x \, dx = 1$，合法了！)*

---

### 2. 第二步：代入蒙特卡洛公式

我们要算的积分真值是（大家都会算）：
$$ I = \int_0^1 x \, dx = 0.5 $$

现在用蒙特卡洛公式，我们要算的是估计量 $I_{est}$：
$$ I_{est} = \frac{1}{N} \sum \frac{f(x_i)}{p(x_i)} $$

把你的函数代进去：
*   $f(x) = x$
*   $p(x) = 2x$

每一个采样点的贡献值（Ratio）是：
$$ \text{贡献} = \frac{f(x)}{p(x)} = \frac{x}{2x} = \frac{1}{2} = 0.5 $$

---

### 3. 第三步：见证奇迹（零方差）

不管你随机抽到的 $x_i$ 是 0.1，还是 0.9，还是 0.534...
代入公式后，**算出来的结果永远是 0.5！**

$$ I_{est} = \frac{1}{N} \underbrace{(0.5 + 0.5 + \dots + 0.5)}_{N \text{个}} = 0.5 $$

*   **采样次数 $N=1$**：结果是 0.5（精确！）。
*   **采样次数 $N=1000$**：结果还是 0.5（精确！）。
*   **方差：** 因为每次的结果都是常数 0.5，**方差恒等于 0**。

这就是**完美的重要性采样**。如果你能找到一个 PDF $p(x)$ 使得它和 $f(x)$ 仅仅只是差一个常数倍（比例一致），你就消除了所有的噪声。

---

### 4. 落地实操：计算机怎么生成符合 $p(x)=2x$ 分布的随机数？

既然这个 $p(x)$ 这么好，我们在写代码时怎么生成符合这个分布的 $x$ 呢？
不能直接用 `Random.value`（那是均匀分布）。

我们要用**累积分布函数（CDF）逆变换法**：

1.  **求 CDF（面积累积）：**
    $$ P(x) = \int_0^x 2t \, dt = x^2 $$
    *(意思是：随机抽一个数，小于 $x$ 的概率是 $x^2$)*

2.  **求逆函数（Inverse CDF）：**
    设均匀随机数 $\xi = x^2$ （$\xi$ 是你代码里的 `Random.value`, 0到1之间）。
    解出 $x$：
    $$ x = \sqrt{\xi} $$

**代码实现（Unity C#）：**

```csharp
// 这里的 f(x) = x
// 我们构造了 p(x) = 2x
float MonteCarloIntegration(int N) {
    float sum = 0;
    for(int i=0; i<N; i++) {
        // 1. 生成样本
        float xi = Random.value; // 均匀分布 0~1
        float x = Mathf.Sqrt(xi); // 变换成符合 p(x)=2x分布 的样本
        
        // 2. 计算 f(x)/p(x)
        float pdf = 2 * x;
        float value = x;
        
        // 3. 累加
        float contribution = value / pdf; // 这一步算出来恒等于 0.5
        sum += contribution;
    }
    return sum / N; // 结果必为 0.5
}
```

### 总结
你的直觉非常准。
**$f(x)$ 和 $p(x)$ 的形状越接近（成正比），$\frac{f(x)}{p(x)}$ 就越接近常数，方差就越小。**
当它们完全成比例时（像 $x$ 和 $2x$），方差消失，蒙特卡洛积分变成了精确积分。
