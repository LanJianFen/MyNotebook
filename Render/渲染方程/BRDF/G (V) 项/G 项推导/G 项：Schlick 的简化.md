### 第一步：Schlick 的“有理分式”模板天才在哪？

在 GPU 里，算一次根号 `sqrt()` 就要花掉好几个时钟周期，这在当年是不可接受的。
我们需要找一个函数，来替换掉精确版 GGX $G_1$ 公式里那个恶心的分母。

Schlick 注意到了精确版 $G_1(v)$ 的两个极端物理性质：
1.  **正视 ($v = 1$)**：无论多粗糙，可见率都极高，$G_1(1)$ 必须逼近 $1$。
2.  **掠射 ($v \to 0$)**：视线几乎和表面平行，可见率极低，$G_1(0)$ 必须逼近 $0$。

在数学上，要满足这两个条件，最便宜、指令最少的平滑曲线是什么？
就是**一阶有理分式（Rational Fraction）**：
$$ f(v) = \frac{v}{av + b} $$

为了保证 $f(1) = 1$，必须满足 $a + b = 1$，即 $a = 1 - b$。
把 $b$ 换个名字叫做 $k$，于是 Schlick 写下了他那著名的万能模板：
**$$ G_{Schlick}(v) = \frac{v}{v(1 - k) + k} $$**

这个模板简直是神作：**它没有任何除法（整个式子只有一次除法），没有任何根号，仅仅通过调节一个参数 $k$，就能完美控制曲线在 $v \to 0$ 时的下降速度！**

---

### 第二步：如何推导出 $k$？（极限渐近法）

既然模板有了，现在我们要用它来拟合精确版的 GGX $G_1$。
先写出我们上一局得出的**精确版 GGX $G_1$**：
$$ G_{exact}(v) = \frac{2v}{v + \sqrt{\alpha^2 + v^2(1 - \alpha^2)}} $$

为了和 Schlick 的模板（分子是 $v$）对齐，我们**把精确版的分子和分母同时除以 2**：
$$ G_{exact}(v) = \frac{v}{0.5v + 0.5\sqrt{\alpha^2 + v^2(1 - \alpha^2)}} $$

现在，我们把精确版的分母，和 Schlick 近似版的分母放在一起比较：
*   **精确版分母**：$D_{exact}(v) = 0.5v + 0.5\sqrt{\alpha^2 + v^2(1 - \alpha^2)}$
*   **近似版分母**：$D_{Schlick}(v) = v(1 - k) + k$

我们要找一个最好的 $k$，让这两个分母尽可能相等。
**怎么找？看曲线的极端情况（极值点）！**

**测试极值 1：当 $v = 1$ 时（正视表面）**
*   $D_{exact}(1) = 0.5(1) + 0.5\sqrt{\alpha^2 + 1 - \alpha^2} = 0.5 + 0.5 = 1$
*   $D_{Schlick}(1) = 1(1 - k) + k = 1$
你看！无论 $k$ 是多少，在 $v=1$ 时它们天然完美匹配！

**测试极值 2：当 $v \to 0$ 时（掠射表面，这是遮蔽发生最剧烈的地方！）**
我们对两个分母同时求 $v \to 0$ 的极限：
*   $D_{exact}(0) = 0.5(0) + 0.5\sqrt{\alpha^2 + 0} = 0.5\alpha = \frac{\alpha}{2}$
*   $D_{Schlick}(0) = 0(1 - k) + k = k$

**见证奇迹的时刻到了！**
为了让近似曲线在最关键的掠射角度和真实物理曲线完美重合，我们必须强制要求这两个极限相等：
**$$ k = \frac{\alpha}{2} $$**

**BOOM！！！这就是答案！**
没有任何玄学，没有任何黑魔法，Brian Karis 等人就是通过让 Schlick 分母在极限情况（$v \to 0$）下精准咬合 GGX 精确分母，用最基础的微积分极限，硬生生推导出了这个统治游戏界好几年的代码：
```glsl
// UE4 早期的标准 G 项代码
float k = alpha / 2.0;
float G_V = dotNV / (dotNV * (1.0 - k) + k);
```

### 第三层：被逼无奈的魔改，为什么还有一个 $k = \frac{(Roughness + 1)^2}{8}$？

如果你看过 UE4 的源码，你肯定会发现，代码里不仅有 $k = \frac{\alpha}{2}$，在算直接光照（Analytical Lights）的时候，还有一个更奇葩的常量：
$k = \frac{(Roughness + 1)^2}{8}$。

这个又是怎么算出来的？
这就要说到理论和艺术结合时的“妥协”了。

1.  **物理与美术的鸿沟**：
    迪士尼（Burley, 2012）在做《无敌破坏王》时发现，物理学家给的 $\alpha$ 并不符合人类对粗糙度的直觉。所以迪士尼做了一个平方映射：$\alpha = Roughness^2$。
    那么按照我们刚才的极限推导：$k = \frac{\alpha}{2} = \frac{Roughness^2}{2}$。

2.  **直接光照的“高光过爆（Hotspot）”惨案**：
    当 Epic Games 把这个 $k$ 用到直接光照时，发现了一个致命问题。分离式的 $G$ 项相乘（上一局我们聊过），会导致粗糙的表面在直接光照下边缘出现异常高亮（能量不守恒，或者说视觉上太假）。

3.  **工程师的“掩耳盗铃”**：
    为了在不增加计算量的前提下压暗这些讨厌的高光，Epic 决定在直接光照下，**强行把粗糙度变大一点**。
    他们对传入的 $Roughness$ 做了一个粗暴的重映射（Remap）：
    $$ Roughness_{新} = \frac{Roughness_{原} + 1}{2} $$
    *(你看，这样一来，原本为 0 的光滑材质变成了 0.5，整体粗糙度被强行拔高了！)*

    现在，把这个新的粗糙度塞进我们刚推导的 $k$ 公式里：
    $$ k = \frac{\alpha_{新}}{2} = \frac{(Roughness_{新})^2}{2} = \frac{\left(\frac{Roughness_{原} + 1}{2}\right)^2}{2} = \frac{(Roughness_{原} + 1)^2}{8} $$

### 总结：理智与疯狂的完美结合

你今天扒开的这个 $k$，正是图形学工业界最真实的一面：
*   **它的骨架，是绝对严谨的数学**：通过求解 $\lim_{v \to 0}$ 极限，把精确版和有理分式完美对接，得出 $k = \frac{\alpha}{2}$。
*   **它的皮囊，是极致压榨的工程妥协**：为了消灭一个 `sqrt()`，心甘情愿使用 Schlick 近似。
*   **它的灵魂，是艺术直觉的强行修正**：为了解决分离式 G 项的视觉 Bug，强行凑出了一个 $\frac{(R+1)^2}{8}$。
