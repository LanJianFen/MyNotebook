### 一、 解剖这一刀：在 $\frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} = 1$ 处切出的山腰横截面

我们来看完整的火山方程：
$$ P^2(x_m, y_m) = \frac{1}{\pi \alpha_x \alpha_y \left( 1 + \frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} \right)^2} $$

现在，我们在满足 **$\frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} = 1$** 的位置水平切出一个椭圆横截面。这个横截面有四个精确的几何指标：

1. **横截面的半长轴（X 方向半宽）**：直接令 $y_m = 0$，解得 **$x_m = \alpha_x$**。
2. **横截面的半短轴（Y 方向半宽）**：直接令 $x_m = 0$，解得 **$y_m = \alpha_y$**。
3. **横截面的面积 $S_{\text{截面}}$**：标准椭圆面积公式，精确等于 **$S_{\text{截面}} = \pi \alpha_x \alpha_y$**。
4. **🚨 关键细节：这一刀切在山腰的什么海拔高度 $Z_{\text{截面}}$ 上？**
   把 $\frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} = 1$ 代入 $P^2(x_m, y_m)$：
   $$ Z_{\text{截面}} = \frac{1}{\pi \alpha_x \alpha_y (1 + 1)^2} = \mathbf{\frac{1}{4 \pi \alpha_x \alpha_y}} = \frac{1}{4} Z_{\text{山顶}} = \mathbf{\frac{1}{4 S_{\text{截面}}}} $$

**请看第 4 点这个极其美妙的几何铁律：**
*   这个椭圆横截面，永远位于**山顶往下四分之三处（即山顶海拔的 $\frac{1}{4}$ 处，正宗的“山腰”）**！
*   而且，**这个山腰横截面的面积 $S_{\text{截面}}$，与它所在的绝对海拔高度 $Z_{\text{截面}}$（以及山顶高度 $Z_{\text{山顶}}$）成严格的【反比关系】**！
    *   横截面面积 $S_{\text{截面}}$ 越**小** $\implies$ 这一刀所在的海拔高度 $Z_{\text{截面}}$（和山顶）就越**高**！
    *   横截面面积 $S_{\text{截面}}$ 越**大** $\implies$ 这一刀所在的海拔高度 $Z_{\text{截面}}$（和山顶）就越**矮**！

### 二、 重新描述四大标准：盯着山腰横截面 $(\alpha_x, \alpha_y)$ 的变形！

设初始状态（`anisotropy = 0`）下，山腰横截面是一个半径为 $\alpha$ 的正圆，截面面积为 $S_0 = \pi \alpha^2$，所在山腰海拔为 $Z_0 = \frac{1}{4\pi\alpha^2}$。

现在把 `anisotropy` 从 $0$ 拉向 $1$，看这个山腰横截面的长、宽、面积和海拔如何变化：

---

#### 1. Disney 2012 / Frostbite 2014：横截面“等面积变形”，所在海拔锁死不变
$$\alpha_x = \frac{\alpha}{\sqrt{1 - 0.9a}}, \qquad \alpha_y = \alpha \sqrt{1 - 0.9a}$$
*   **横截面长宽变化**：横截面的 X 半轴被拉长（最多到 $3.16\alpha$），Y 半轴同步按相同比例缩短（最少到 $0.316\alpha$）。
*   **横截面面积 $S_{\text{截面}}$**：$S = \pi \left(\frac{\alpha}{\text{aspect}}\right) (\alpha \cdot \text{aspect}) = \mathbf{\pi \alpha^2}$ —— **横截面面积恒定不变！**
*   **横截面所在海拔 $Z_{\text{截面}}$**：因为面积 $S$ 没变，所以 $\frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} = 1$ 这个横截面**一直停留在原来的海拔高度 $Z_0 = \frac{1}{4\pi\alpha^2}$ 上**，山顶高度也完全不变。山体只是在同一海拔高度上把圆形的腰身扭成了椭圆。

---

#### 2. Sony 2017 / Filament / UE5：横截面“周长（半轴和）不变、面积剧烈坍缩”，海拔被迫冲向云霄
$$\alpha_x = \alpha(1 + a), \qquad \alpha_y = \alpha(1 - a)$$
*   **横截面长宽变化**：横截面的 X 半轴均匀拉长（最多到 $2\alpha$），Y 半轴均匀缩短（一路缩向 $0$）。长宽之和 $\alpha_x + \alpha_y = 2\alpha$ 保持不变。
*   **横截面面积 $S_{\text{截面}}$**：$S = \pi \alpha^2 (1 - a^2)$。随着 $a \to 1$，Y 轴宽度归零，**这个山腰横截面的面积急剧萎缩，最终趋近于 $0$**！
*   **横截面所在海拔 $Z_{\text{截面}}$**：因为横截面面积 $S \to 0$，根据反比铁律 $Z_{\text{截面}} = \frac{1}{4S}$，**这个变窄的山腰横截面（连同山顶一起）在垂直方向上被疯狂往上推高，海拔直冲 $+\infty$**！
    *(换句话说：山腰越收越紧，整座山在上半部分变成了一道又窄又高的陡峭窄峰！)*

---

#### 3. glTF 2023 (`KHR_materials_anisotropy`)：横截面“单向拉宽、面积膨胀”，海拔整体下沉
$$\alpha_x = \text{lerp}(\alpha, 1.0, a^2), \qquad \alpha_y = \alpha$$
*   **横截面长宽变化**：横截面的 Y 半轴宽度死死固定为 $\alpha$ 不变，X 半轴单向拉长直到 $1.0$。
*   **横截面面积 $S_{\text{截面}}$**：$S = \pi \alpha_x \alpha$。因为一边不变、另一边变长，**山腰横截面的面积不断膨胀变大**！
*   **横截面所在海拔 $Z_{\text{截面}}$**：因为横截面面积变大了，为了維持整座山的总积分体积为 $1$，**这个变胖的山腰横截面（连同山顶一起）所在的海拔高度 $Z_{\text{截面}} = \frac{1}{4S}$ 不断往下降落变矮**！整座山变成了一个宽阔低矮的缓坡。

---

#### 4. OpenPBR 2024：横截面“外接对角线不变、后期面积坍缩”，海拔后期飙升
$$\alpha_x = \frac{\sqrt{2}\alpha}{\sqrt{1 + (1-a)^2}}, \qquad \alpha_y = \alpha_x (1 - a)$$
*   **横截面长宽变化**：横截面椭圆的半长轴平方与半短轴平方之和 $\alpha_x^2 + \alpha_y^2 = 2\alpha^2$ 恒定（即横截面外接矩形的对角线长度锁死不变）。X 半轴最多拉长到 $1.414\alpha$，Y 半轴缩向 $0$。
*   **横截面面积 $S_{\text{截面}}$**：$S = \pi \alpha^2 \frac{2(1-a)}{1 + (1-a)^2}$。当 $a \to 1$ 时，横截面面积同样萎缩向 $0$。
*   **横截面所在海拔 $Z_{\text{截面}}$**：随着山腰横截面面积萎缩，它所在的海拔高度（和山顶）同样在后期急剧拔高冲向 $+\infty$。

### 三、 补充视角：如果我们在【固定绝对海拔高度 $P^2(x_m, y_m) = C$】切一刀呢？

刚才我们看的是满足 $\frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} = 1$ 的截面（它的海拔会跟着山顶一起升降）。
如果你说：**“我不跟着山顶升降！我就死死固定在绝对海拔高度 $P^2(x_m, y_m) = C$（比如固定在初始山腰高度 $C = \frac{1}{4\pi\alpha^2}$）水平切一刀！”**

我们把 $P^2(x_m, y_m) = C$ 移项开方，立刻就能写出**固定海拔 $C$ 处的真实椭圆方程**：
$$ \frac{x_m^2}{\alpha_x^2} + \frac{y_m^2}{\alpha_y^2} = \sqrt{\frac{1}{C \pi \alpha_x \alpha_y}} - 1 $$

你看，在固定海拔高度 $C = \frac{1}{4\pi\alpha^2}$ 处切一刀：
*   **Disney**：因为 $\pi\alpha_x\alpha_y = \pi\alpha^2$ 不变，右边恒等于 $\sqrt{4} - 1 = 1$，截出来的椭圆面积恒定为 $\pi\alpha^2$。
*   **glTF 2023**：当 $\alpha_x$ 变大到一定程度，使得山顶都矮于海拔 $C$（即 $\frac{1}{\pi\alpha_x\alpha} < C$）时，右边小于 $0$——**这一刀切在半空中，连山体都碰不到了（截面直接消失）**！因为山已经塌陷到海拔 $C$ 以下了！
*   **Sony / OpenPBR**：当 $a \to 1$ 时，$\alpha_y \to 0$，虽然山顶冲向了无穷高，但在固定海拔 $C$ 处的横截面面积 $S(C) = \sqrt{\frac{\pi\alpha_x\alpha_y}{C}} - \pi\alpha_x\alpha_y$ 同样会随着 $\alpha_x\alpha_y \to 0$ 而**收缩成一条面积为 $0$ 的细线**！
