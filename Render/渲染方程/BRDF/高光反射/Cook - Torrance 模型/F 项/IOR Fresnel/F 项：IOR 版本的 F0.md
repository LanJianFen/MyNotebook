一旦你把公式里的 `ior` 理解为**相对折射率 $\eta = \frac{n_2}{n_1}$**，在数学和物理上，它不仅**不需要大于 1**，而且它具备一个极其优美的数学性质：**倒数对称性（Reciprocal Symmetry）**！

但是，如果你允许传入小于 $1.0$ 的相对 `ior`（即光密射向光疏，$0 < \text{ior} < 1$），你在写代码和选择近似模型时，会立刻面临**三个层次的生死考验**。我们一层层扒开看：

---

### 第一层：单看 $F_0 = \left(\frac{\text{ior} - 1}{\text{ior} + 1}\right)^2$ 本身 —— 绝对不需要大于 1！

从纯代数的角度来看，为什么这个公式根本不在乎 `ior` 是大于 1 还是小于 1（只要 $\text{ior} > 0$）？
因为外面套了一个**平方**！

假设介质 A 是空气（$n = 1.0$），介质 B 是玻璃（$n = 1.5$）：
1. **光从空气垂直射入玻璃（光疏 $\to$ 光密）**：
   相对折射率 $\eta_1 = \frac{1.5}{1.0} = \mathbf{1.5} > 1$。
   $$ F_0(1.5) = \left( \frac{1.5 - 1}{1.5 + 1} \right)^2 = \left( \frac{+0.5}{2.5} \right)^2 = (+0.2)^2 = \mathbf{0.04} $$

2. **光从玻璃内部垂直射向空气（光密 $\to$ 光疏，比如水底的气泡、或清漆层射向低折射率底层）**：
   相对折射率 $\eta_2 = \frac{1.0}{1.5} = \mathbf{\frac{2}{3}} \approx 0.6667 < 1$。
   我们直接把这个小于 1 的 $\frac{2}{3}$ 塞进同一个公式里：
   $$ F_0\left(\frac{2}{3}\right) = \left( \frac{\frac{2}{3} - 1}{\frac{2}{3} + 1} \right)^2 = \left( \frac{-\frac{1}{3}}{\frac{5}{3}} \right)^2 = (-0.2)^2 = \mathbf{0.04} $$

**数学通式证明（将 $\eta$ 替换为倒数 $\frac{1}{\eta}$）：**
$$ F_0\left(\frac{1}{\eta}\right) = \left( \frac{\frac{1}{\eta} - 1}{\frac{1}{\eta} + 1} \right)^2 = \left( \frac{1 - \eta}{1 + \eta} \right)^2 = \left( - \frac{\eta - 1}{\eta + 1} \right)^2 \equiv \left( \frac{\eta - 1}{\eta + 1} \right)^2 = F_0(\eta) $$

**物理意义（亥姆霍兹光路可逆性）：**
在垂直入射（$0^\circ$）的那一瞬间，无论是光从空气进玻璃，还是从玻璃出空气，这道交界面反弹的能量比例**永远一模一样（都是 $4\%$）**！
所以在计算 $F_0$ 时，你完全不需要规定 `ior >= 1.0`，只要 `ior > 0.0`，算出来的 $F_0$ 永远是绝对正确的！

### 第二层：工程代码陷阱 —— 如果允许 `ior < 1`，绝对禁止写 `pow(x, 2.0)`！

这正是我在前面审查你的 `glTF 2021` 代码时，特意提醒你的那个 GPU 底层硬件陷阱！

当你允许 `ior < 1.0`（比如传入了 `0.667`）时，括号里的底数：
$$ x = \frac{\text{ior} - 1.0}{\text{ior} + 1.0} = -0.2 \quad (\text{变成了负数！}) $$

*   **如果你在 HLSL 里写的是 `pow((ior - 1.0h) / (ior + 1.0h), 2.0h)`**：
    HLSL 编译器在处理 `pow(base, exp)` 时，如果没能触发常数展开优化，硬件底层执行的机器指令是：
    $$ \text{pow}(x, y) \implies \text{exp2}(y \times \mathbf{\text{log2}(x)}) $$
    当 $x = -0.2$（负数）塞进 `log2(-0.2)` 时，对数函数定义域报错，GPU 寄存器直接吐出 **`NaN`（坏死黑块）**！
*   **如果你在 HLSL 里写的是自乘 `r * r`**：
    ```hlsl
    half r = (ior - 1.0h) / (ior + 1.0h);
    half F0 = r * r; // (-0.2) * (-0.2) = +0.04，绝对安全！
    ```
    硬件直接走一次 `MUL` 乘法指令，正负号瞬间抵消，哪怕传入小于 1 的 `ior` 也稳如泰山！

### 第三层：全角度曲线陷阱 —— 当 `ior < 1` 时，后续的 $F(\theta)$ 谁能算对？

虽然在 $0^\circ$ 正视时，传入 $\eta = 1.5$ 和传入 $\eta = 0.667$ 算出来的 $F_0$ 都是 $0.04$；
**但是！一旦视线倾斜（$\theta_i > 0^\circ$），它俩的物理命运就彻底分道扬镳了！**

1. **如果你后面接的是【标准 5 次方 Schlick 近似】**：
   因为 Schlick 公式只吃 $F_0$，不吃 `ior` 本身！
   你传 $\eta = 1.5$ 算出来 $F_0 = 0.04$；你传 $\eta = 0.667$ 算出来**也是** $F_0 = 0.04$。
   导致 Schlick 在这两种情况下，画出了**完全一模一样的曲线**（都在 $90^\circ$ 才到 $1.0$）！它彻底算错了 $\eta = 0.667$ 在临界角（$41.8^\circ$）就应该提前到达 $1.0$（全反射 TIR）的物理事实！
   *(注：如果非要用 Schlick 强行支持 `ior < 1`，图形学界有一个补丁叫“Refracted Schlick”，需要用斯涅尔定律先把入射角余弦 `VdotH` 替换成折射角余弦 `cosTheta_t` 再做 5 次方，一旦发生全反射直接返回 1.0。)*

2. **如果你后面接的是【OpenPBR 的麦克斯韦精确公式 `F_Dielectric_Exact`】**：
   **它原生就完美支持 `ior < 1.0`！根本不需要规定 `ior > 1`！**
   不信你看我在 `F_Dielectric_Exact_OpenPBR` 里给你写的这两行代码：
   ```hlsl
   half eps = sign(ior - 1.0h) * sqrt(saturate(specular * F_s));
   half eta_prime = (1.0h + eps) / max(1.0h - eps, 1e-5h);
   ```
   **看到那个 `sign(ior - 1.0h)` 了吗？！**
   * 当 `ior > 1.0`（光疏 $\to$ 光密）时，`sign` 是 $+1$，反推出来的 `eta_prime > 1.0`；
   * 当 `ior < 1.0`（光密 $\to$ 光疏）时，虽然 $F_s$ 平方后丢失了正负号，但 **`sign(ior - 1.0h)` 等于 $-1$，帮你把负号找了回来**！使得反推出来的 `eta_prime` 依然精准小于 $1.0$（比如还原回 $0.667$），随后进入 `g2 = eta_prime^2 + c^2 - 1`，在 $41.8^\circ$ 时精准触发 `g2 < 0` 的全反射分支！
