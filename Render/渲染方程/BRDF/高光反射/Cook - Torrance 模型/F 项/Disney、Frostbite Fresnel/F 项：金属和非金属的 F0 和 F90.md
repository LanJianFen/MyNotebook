
### 一、 逆向求解：`0.08 * Specular` 与 `0.16 * Reflectance²` 到底对应多少折射率 $n$？

在物理光学中，光从空气（$n_{\text{air}} \approx 1.0$）垂直射入电介质（折射率为 $n$）时，基础反射率 $F_0$ 的公式为：
$$ F_0 = \left( \frac{n - 1}{n + 1} \right)^2 $$

现在，我们做一次初中代数**逆向求解**，把折射率 $n$ 用 $F_0$ 表示出来：
1. 两边开根号（因为 $n \ge 1$，直接取正）：$\sqrt{F_0} = \frac{n - 1}{n + 1}$
2. 交叉相乘移项：$n \sqrt{F_0} + \sqrt{F_0} = n - 1$
3. 解出折射率 $n$ 的终极反推公式：
**$$ n = \frac{1 + \sqrt{F_0}}{1 - \sqrt{F_0}} $$**

有了这把钥匙，我们直接把两大流派的参数代进去，看看它们各自的物理统治范围：

---

#### 1. Disney (2012) & UE4/UE5 流派：$F_0 = 0.08 \times \text{Specular}$
美术滑杆 `Specular` 的范围是 $[0.0, 1.0]$，因此 $F_0$ 的范围是 **$[0.00, 0.08]$**。

*   **当 `Specular = 0.0` 时**：$F_0 = 0 \implies n = \frac{1+0}{1-0} = \mathbf{1.00}$（空气/真空，完全无反射）。
*   **当 `Specular = 0.5`（默认）时**：$F_0 = 0.04 \implies \sqrt{F_0} = 0.2 \implies n = \frac{1 + 0.2}{1 - 0.2} = \frac{1.2}{0.8} = \mathbf{1.50}$（标准玻璃、塑料、清漆）。
*   **当 `Specular = 1.0`（上限）时**：$F_0 = 0.08 \implies \sqrt{F_0} \approx 0.2828 \implies n = \frac{1.2828}{0.7172} \approx \mathbf{1.7888 \approx 1.79}$（蓝宝石、红宝石）。

**致命缺陷**：由于 $F_0$ 是线性变化的，而求 $n$ 需要开根号 $\sqrt{F_0}$，导致这个滑杆相对于折射率 $n$ 是**非线性的**！并且它的折射率上限死死卡在了 **$1.79$**，根本无法表示立方氧化锆（$2.15$）或钻石（$2.42$）。

---

#### 2. Frostbite (2014) & Filament (2018) 流派：$F_0 = 0.16 \times \text{Reflectance}^2$
美术滑杆 `Reflectance`（记作 $R$）的范围是 $[0.0, 1.0]$，因此 $F_0$ 的范围是 **$[0.00, 0.16]$**。

**请看 Lagarde 设计这个平方公式时的绝妙代数心机：**
当我们把 $F_0 = 0.16 \times R^2$ 代入上面的折射率反推公式时，$\sqrt{F_0}$ 里的根号和 $R^2$ 的平方**完美抵消了**！
$$ \sqrt{F_0} = \sqrt{0.16 \times R^2} = \mathbf{0.4 R} $$
于是，折射率 $n$ 与滑杆 $R$ 的关系变成了极其丝滑的代数式：
**$$ n = \frac{1 + 0.4 R}{1 - 0.4 R} $$**

我们来算它的刻度表：
*   **`Reflectance = 0.0`**：$F_0 = 0.00 \implies n = \mathbf{1.00}$（空气）。
*   **`Reflectance = 0.35`**：$F_0 \approx 0.02 \implies n = \frac{1.14}{0.86} \approx \mathbf{1.33}$（纯净水、冰）。
*   **`Reflectance = 0.50`（默认）**：$F_0 = 0.04 \implies n = \frac{1.2}{0.8} = \mathbf{1.50}$（塑料、玻璃）。
*   **`Reflectance = 1.00`（上限）**：$F_0 = 0.16 \implies n = \frac{1 + 0.4}{1 - 0.4} = \frac{1.4}{0.6} = \mathbf{2.333}$（无限逼近真钻石的 $2.42$！）。

**对比一览表：**

| 滑杆位置 | Disney/UE (`0.08 * S`) 对应的 $F_0$ 与 IOR | Frostbite/Filament (`0.16 * R²`) 对应的 $F_0$ 与 IOR | 对应现实物理材质 |
| :--- | :--- | :--- | :--- |
| **`0.0`** | $F_0 = 0.00 \quad (n = 1.00)$ | $F_0 = 0.00 \quad (n = 1.00)$ | 空气 |
| **`0.35`** | $F_0 = 0.028 \ (n = 1.40)$ | $F_0 = 0.02 \quad (n = 1.33)$ | **水 / 眼泪**（寒霜精度极佳） |
| **`0.5` (默认)** | $F_0 = 0.04 \quad (n = 1.50)$ | $F_0 = 0.04 \quad (n = 1.50)$ | **通用塑料 / 玻璃 / 木器漆** |
| **`1.0` (最大)** | $F_0 = 0.08 \quad (n = 1.79)$ | $F_0 = 0.16 \quad (n = 2.33)$ | 刚玉宝石 ($1.79$) vs **准钻石 ($2.33$)** |

### 二、 为什么此时 $F_0$ 的 RGB 三个通道都是相同的数字？什么材质是这样的？

你观察得非常仔细：在上面这两个公式里，算出来的 $F_0$ 是一个标量（比如 `0.04`），赋给 `float3` 后变成了 `(0.04, 0.04, 0.04)`——**红、绿、蓝三个通道完全相等（无色/消色差，Achromatic）**。

**现实中什么材质是这样的？**
**答案是：地球上 99% 的非金属（绝缘体 / 电介质，Dielectrics）全都是这样的！**

#### 物理原因：正常色散极弱（Weak Normal Dispersion）
塑料、木头、石头、皮肤、水、陶瓷、普通布料、树叶，这些统称为电介质。
虽然在严格的光学中，电介质对不同波长的光也有一点点折射率差异（比如玻璃对红光 $650\text{nm}$ 的折射率是 $1.514$，对蓝光 $450\text{nm}$ 的折射率是 $1.528$，这叫“色散”，也是三棱镜能分出彩虹的原因）。

**但是！我们来算算这点差异对反射率 $F_0$ 的影响有多大：**
*   红光通道 $F_{0,R} = \left(\frac{1.514 - 1}{1.514 + 1}\right)^2 = \mathbf{0.0418}$
*   蓝光通道 $F_{0,B} = \left(\frac{1.528 - 1}{1.528 + 1}\right)^2 = \mathbf{0.0436}$

看到了吗？红绿蓝三个通道的反射率差距只有 **$0.0018$（不到千分之二）**！
在反射高光中，这点微弱的差异人眼根本分辨不出来（色散只有在光线穿透厚玻璃发生角度偏折时才明显）。
因此，在物理渲染中有一条铁律：**所有普通非金属的表面镜面高光，都是不带颜色的（RGB 三通道相等），高光永远直接呈现光源本身的颜色（比如白光照射下的红色塑料球，它上面的高光点是纯白色的，而不是红色的）！**

### 三、 遇到 $F_0$ 三个通道不同（有色高光）的时候怎么办？

在现实物理世界和渲染管线中，什么时候会出现 **$F_0$ 的 R、G、B 三个通道数值截然不同** 的情况？
一共有 **三大类材质**，现代引擎针对它们有着完全不同的处理方案：

#### 情况 1：金属 / 导体（Conductors，如黄金、紫铜）—— 最常见的情况
*   **物理原因**：金属的消光系数 $\kappa(\lambda)$ 随波长剧烈变化。比如黄金强烈吸收蓝光（$F_{0,B} \approx 0.33$），强烈反射红光（$F_{0,R} \approx 1.0$）和绿光（$F_{0,G} \approx 0.76$）。
*   **引擎怎么办？**
    这就是 **金属度工作流（Metallic Workflow）** 存在的意义！
    当遇到金属时，把 `Metallic` 设为 `1.0`。
    通过代码 `F0 = lerp(F0_dielectric, BaseColor, Metallic);`，引擎直接抛弃了前面那个三通道相等的标量 `F0_dielectric`，**直接把 RGB 三通道各不相同的 `BaseColor` 贴图，原封不动地拿过来当成 $F_0$！**

#### 情况 2：半金属、特种涂层与有色高光非金属（Colored Specular Dielectrics）
在极少数非金属或复合材料中，高光确实会带颜色：
*   比如某些**高浓度有机染料/油墨**（由于反常色散效应，表面高光会泛出互补色铜光，称为 Bronzing 效应）；
*   比如**丝绸、天鹅绒等织物**，或者美术为了风格化强行要求给非金属高光染色。
*   **引擎怎么办？**
    1. **Disney 2012 的做法**：就是你之前写过的 `SpecularTint`（把 `BaseColor` 除以亮度得到色相 `Ctint`，乘在 `0.08 * Specular` 上，强行把标量变成 RGB 向量）。
    2. **现代标准（glTF `KHR_materials_specular` & OpenPBR）的做法**：
       现代标准认为 Disney 强行只能染成 `BaseColor` 同色相太死板了（现实中的反常色散往往是异色的）。
       于是现代引擎直接增加了一个独立的 **`float3 specular_color`（高光颜色）** 输入参数！
       计算公式直接变为：
       $$ \mathbf{F}_{0,\text{dielectric}} = \left(\frac{\text{IOR} - 1}{\text{IOR} + 1}\right)^2 \times \mathbf{C}_{\text{specular\_color}} \times w_{\text{specular\_weight}} $$
       这样，即使 `Metallic = 0`，绝缘体的 $F_0$ 也能拥有独立的 RGB 三通道颜色！

#### 情况 3：纳米薄膜干涉（Thin-Film Iridescence，如甲虫壳、肥皂泡、机油）
*   **物理原因**：表面有一层几百纳米厚的透明薄膜，光波发生相干抵消，导致从不同角度看去，$F$ 的 R、G、B 通道随视角 $\mathbf{V}\cdot\mathbf{H}$ 呈现出周期性的正弦波震荡（彩虹色）。
*   **引擎怎么办？**
    在 `Fresnel.hlsl` 中，不再使用普通的 Schlick 公式，而是直接调用 **波动光学薄膜干涉函数（Airy 干涉近似）**，根据薄膜厚度动态算出 RGB 三通道完全不同的菲涅尔反射率。

### 四、 现实物理世界中，非金属和金属的 $F_0$、$F_{82}$（凹陷点）与 $F_{90}$ 数值到底是多少？

在全部转化成**线性空间（Linear Space，未做 Gamma 校正）**的 RGB 能量比例后，现实世界的数据铁律如下：

#### 1. 现实中的 $F_{90}$（$90^\circ$ 绝对掠射角）
*   **微观绝对光滑表面（无论是金属还是非金属）**：
    根据麦克斯韦电磁方程组，当入射角 $\theta_i \to 90^\circ$（$\cos\theta_i \to 0$）时，所有物质的分母都会与分子相等。
    因此，在物理上，**所有物质的微观 $F_{90}$ 永远、严格等于纯白色 `(1.00, 1.00, 1.00)`（即 100% 反射）！**
*   **那为什么引擎里允许把 $F_{90}$ 调低（小于 1.0）？**
    因为现实中存在两类情况：
    1. **极细微的次像素孔洞/绒毛/吸光涂层**（比如黑丝绒、碳纳米管涂层 Vantablack、极度粗糙的风化岩石）：光线在掠射角被微观陷阱吸收，宏观上看不出边缘白光，所以在 glTF 扩展中用 `specular_weight < 1.0` 把 $F_{90}$ 压低。
    2. **金属的 $82^\circ$ 拟布儒斯特角凹陷（Fresnel Dip）**：金属虽然在极限 $90^\circ$ 是 `1.0`，但在 $75^\circ \sim 85^\circ$（肉眼看到的物体边缘轮廓区）会剧烈变暗！在不支持 `F82` 七次方公式的实时渲染（如 UE5 默认 G-Buffer 模式）中，美术会把金属的 $F_{90}$ 设为 $82^\circ$ 时的暗色（比如 `0.6`），用来近似模拟边缘变暗。

---

#### 2. 非金属（绝缘体 / Dielectrics）的真实 $F_0$ 数值表
非金属的消光系数 $\kappa = 0$，其 $F_0$ 极低（通常在 **$2\% \sim 8\%$**，仅有极少数宝石超过 $10\%$），且 RGB 三通道几乎完全相等（无色）：

| 现实非金属材质 | 物理折射率 (IOR $n$) | 线性空间真实 $F_0$ (RGB) | 备注 |
| :--- | :--- | :--- | :--- |
| **水 / 冰 / 眼泪** | $1.333$ | `(0.020, 0.020, 0.020)` | 常见液体的最低反射率基准 |
| **人类皮肤 / 肌肉组织** | $1.38 \sim 1.40$ | `(0.028, 0.028, 0.028)` | 引擎中皮肤 Shader 常锁死为 `0.028` |
| **塑料 / 普通玻璃 / 清漆 / 木材** | $1.49 \sim 1.52$ | `(0.040, 0.040, 0.040)` | **PBR 工业界万能默认值 (4%)** |
| **红宝石 / 蓝宝石 / 玉石** | $1.76 \sim 1.78$ | `(0.076, 0.076, 0.076)` | 传统 `0.08 * Specular` 的极限天花板 |
| **水晶 / 燧石玻璃 (Flint Glass)** | $1.80 \sim 1.90$ | `(0.082, 0.082, 0.082) ~ (0.096)` | 高折射率人造光学玻璃 |
| **钻石 (Diamond)** | $2.417$ | `(0.172, 0.172, 0.172)` | 自然界透明宝石之王 (17.2%) |
| **二氧化钛涂层 (特殊高反电介质)** | $2.61$ | `(0.199, 0.199, 0.199)` | 非金属的理论上限区域 (~20%) |

> **🚨 铁律禁区**：自然界中**绝对不存在** $F_0$ 在 `0.20 ~ 0.45` 之间的常见均质物质！这个区间被称为 PBR 的 **“无人区（No Man's Land）”**（只有极少数半导体如硅在特定波段落入此区间）。

---

#### 3. 金属（导体 / Conductors）的真实 $F_0$ 与 $F_{82}$（边缘暗带）数值表
金属因为存在巨大的虚部消光系数 $\kappa$，其 $F_0$ 极高（全部在 **$50\% \sim 99\%$** 之间），且具有显著的三通道色彩差异和 $82^\circ$ 边缘凹陷：

| 现实金属材质 | 线性空间 $0^\circ$ 真实 $\mathbf{F}_0$ (RGB) | $82^\circ$ 凹陷点真实反射率 $\mathbf{F}(82^\circ)$ | 对应的 $\mathbf{T}_{82}$ (Edge Tint 缩放比例) | 视觉特征 |
| :--- | :--- | :--- | :--- | :--- |
| **纯银 (Silver)** | `(0.972, 0.960, 0.915)` | `(0.96, 0.95, 0.90)` | `(0.99, 0.99, 0.98)` | 反射率最高，边缘几乎无凹陷 |
| **黄金 (Gold)** | `(1.000, 0.766, 0.336)` | `(0.95, 0.79, 0.45)` | `(0.95, 0.96, 0.85)` | 蓝光吸收极强，边缘微偏暖红 |
| **紫铜 (Copper)** | `(0.955, 0.638, 0.538)` | `(0.93, 0.70, 0.62)` | `(0.96, 0.95, 0.90)` | 红光极强，绿蓝相近呈玫瑰金色 |
| **铝 (Aluminium)** | `(0.913, 0.922, 0.924)` | `(0.74, 0.77, 0.81)` | **`(0.79, 0.82, 0.86)`** | **$0^\circ$ 极亮，但 $82^\circ$ 剧烈变暗发灰！** |
| **铁 (Iron)** | `(0.562, 0.565, 0.578)` | `(0.52, 0.53, 0.56)` | **`(0.76, 0.77, 0.79)`** | 整体偏暗，边缘有明显灰暗过渡带 |
| **铬 (Chromium)** | `(0.549, 0.556, 0.554)` | `(0.48, 0.50, 0.53)` | **`(0.70, 0.72, 0.76)`** | 边缘凹陷最剧烈的典型工业金属 |

*(你看铝、铁、铬这三种工业界最常用的金属：它们的 $\mathbf{T}_{82}$ 都在 `0.70 ~ 0.85` 左右！如果用老式 Schlick 强行把 $82^\circ$ 拉高，铝和铁看起来就会像涂了白漆的塑料。这就是为什么 UE5 和 OpenPBR 必须引入 F82！)*
