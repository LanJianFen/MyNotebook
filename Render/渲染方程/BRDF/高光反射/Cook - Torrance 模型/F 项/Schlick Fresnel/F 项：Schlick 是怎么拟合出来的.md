
### 回到 1994 年 —— Schlick 到底是怎么拟合出那个“5次方”的？

现在我们知道了，精确的菲涅尔函数是一个以 $\cos\theta_i$（为书写清爽，下面我们记 $u = \cos\theta_i = \mathbf{V} \cdot \mathbf{H} \in [0, 1]$）为自变量的函数 $F(u)$。

在 1994 年，法国学者 Christophe Schlick 发表了著名论文《*An Inexpensive BRDF Model for Physically-based Rendering*》。
他看着极其庞大的精确菲涅尔方程（这里的 g 需要看 OpenPBR 的具体说明)：
$$ F_{\text{exact}}(u) = \frac{1}{2} \left( \frac{g - u}{g + u} \right)^2 \left[ 1 + \left( \frac{u(g + u) - 1}{u(g - u) + 1} \right)^2 \right], \quad \text{其中 } g = \sqrt{n^2 + u^2 - 1} $$
这式子又要开根号，又要算好几次除法，当时的 CPU 根本跑不动。

Schlick 作为一个数学功底极强的学者，决定寻找一个**最简单的多项式函数 $\tilde{F}(u)$** 来逼近它。他的推导遵循了极其严密的 **“边界锚定 + 导数平坦度观察”** 三部曲：

#### 1. 第一步：锁死两端的绝对边界条件（Boundary Conditions）
无论什么材质，精确的 $F(u)$ 在区间两端都有两个铁打不动的值：
*   **右端点（垂直入射，$\theta_i = 0^\circ \implies u = 1$）**：
    函数值必须精确等于基础反射率：$F(1) = F_0$。
*   **左端点（掠射角，$\theta_i = 90^\circ \implies u = 0$）**：
    函数值必须精确等于全反射极限：$F(0) = F_{90} = 1$。

为了最简单地连接 $(u=1, F=F_0)$ 和 $(u=0, F=1)$ 这两个点，任何懂代数的工程师都会立刻写下基于 $(1 - u)$ 的幂函数插值模板：
$$ \tilde{F}(u) = F_0 + (1 - F_0)(1 - u)^p $$
*(验证：当 $u=1$ 时，后面那项为 0，等于 $F_0$；当 $u=0$ 时，后面那项为 $1^p = 1$，等于 $1$。无论指数 $p$ 取什么正数，两端永远 100% 严丝合缝！)*

---

#### 2. 第二步：为什么指数 $p$ 必须是 5？（函数高阶导数的秘密）

接下来的问题是：**指数 $p$ 到底取多少，才能让中间 $(0 < u < 1)$ 的曲线形状，跟那个带着根号的麦克斯韦精确公式完全贴合？**

我们把真实的物理菲涅尔曲线 $F_{\text{exact}}(u)$ 画出来（以常见折射率 $n = 1.5$，即 $F_0 = 0.04$ 为例），会发现一个极其显著的物理特征：
**“极度漫长的平坦期，与末端极其陡峭的拉升”！**

*   当入射角从 $0^\circ$ 变到 $45^\circ$（$u$ 从 $1.0$ 降到 $0.707$）时：真实反射率从 $0.040$ 仅仅变成了 $0.050$！**几乎是一条水平直线！**
*   当入射角到了 $60^\circ$（$u = 0.5$）时：真实反射率也才刚刚到 $0.089$！
*   只有当入射角超过 $70^\circ \sim 90^\circ$（$u$ 从 $0.34$ 跌向 $0$）时，反射率才像坐火箭一样猛冲向 $1.0$！

**从微积分（泰勒展开 Taylor Expansion）的角度看，为什么真实曲线在 $u = 1$ 附近那么平？**
如果你对精确公式 $F_{\text{exact}}(u)$ 在 $u = 1$（即 $\theta_i = 0^\circ$）处关于 $(1 - u)$ 做泰勒级数展开，求它的一阶导数、二阶导数：
你会惊奇地发现：
由于 $R_s(u)$ 在 $u=1$ 附近是向上微弯的，而 $R_p(u)$ 在 $u=1$ 附近是**向下微弯的（因为它要先下降去奔向布儒斯特角 $R_p=0$！）**。
当非偏振光把两者求平均 $\frac{1}{2}(R_s + R_p)$ 时，**$R_s$ 的上升趋势和 $R_p$ 的下降趋势在 $u=1$ 附近发生了奇迹般的互相抵消！**

这导致精确函数 $F_{\text{exact}}(u)$ 在 $u=1$ 处的一阶导数、二阶导数、甚至三阶导数的数值都**极其微小，几乎接近于 0**！

而在我们的多项式模板 $\tilde{F}(u) = F_0 + (1 - F_0)(1 - u)^p$ 中：
要想让函数在 $u = 1$ 处的前 $p-1$ 阶导数全部等于 0（从而呈现出那段漫长的水平直线），指数 $p$ 就必须足够大！

---

#### 3. 第三步：最小二乘法与整数指令的最终拍板

Schlick 对自然界常见的绝缘体（$n \in [1.3, 2.5]$）和部分导体进行了全局 $L^2$ 范数误差（均方根误差）最小化拟合测试：

我们直接拿 $n = 1.5$（$F_0 = 0.04$）、在入射角 $60^\circ$（即 $u = \mathbf{V} \cdot \mathbf{H} = 0.5$）这个最关键的转折点来对比不同指数 $p$ 算出来的结果：
*   **麦克斯韦物理精确值 $F_{\text{exact}}(0.5)$** = **$0.0892$**
*   如果取 $p = 3$：$\tilde{F}(0.5) = 0.04 + 0.96 \times (0.5)^3 = 0.1600$ （误差极大，高光严重泛白！）
*   如果取 $p = 4$：$\tilde{F}(0.5) = 0.04 + 0.96 \times (0.5)^4 = 0.1000$ （还是偏高）
*   **如果取 $p = 5$**：$\tilde{F}(0.5) = 0.04 + 0.96 \times (0.5)^5 = 0.04 + 0.96 \times 0.03125 = \mathbf{0.0700}$ （极其接近！）

再看 $75^\circ$（$u = 0.2588$）时的陡峭爬升段：
*   **麦克斯韦物理精确值 $F_{\text{exact}}(0.2588)$** = **$0.253$**
*   **取 $p = 5$ 的 Schlick 值**：$0.04 + 0.96 \times (1 - 0.2588)^5 = \mathbf{0.254}$ （**误差仅千分之一！几乎完美重合！**）

更妙的是，在计算机底层：
如果选一个小数（比如 $p = 4.87$），CPU/GPU 必须调用极度昂贵的超越函数 `exp(4.87 * log(x))`。
而选整数 **$p = 5$**，在代码里只需要 **3 次极其廉价的硬件寄存器乘法**：
```hlsl
half x = 1.0h - VdotH;
half x2 = x * x;      // 第1次乘法: x^2
half x4 = x2 * x2;    // 第2次乘法: x^4
half x5 = x4 * x;     // 第3次乘法: x^5
```

### 金属的 $\tilde{n} = n + i\kappa$ 是复数，为什么实数 Schlick 公式也能处理？

这是一个极其深刻的问题！很多程序员用了十年 `lerp(0.04, BaseColor, metallic)`，却从来没想过：**复数的虚部 $i = \sqrt{-1}$ 到底去哪儿了？**

答案分为两层：**“能量求模消去虚数”** 与 **“绕过复折射率的参数化偷家”**。

#### 第一层：虽然折射率是复数，但反射率 $F(\theta_i)$ 永远是纯实数！
在波动光学中，复折射率 $\tilde{n} = n + i\kappa$ 代入麦克斯韦方程后，算出来的**电场振幅反射系数 $r_s, r_p$ 确实是复数**（复数代表反射光波不仅振幅变了，连**相位 Phase** 都发生了偏移）。

但是！我们在渲染器（几何光学/辐射度量学）里关心的不是电场的相位，而是**光的能量（功率）**！
在复变函数中，电磁波的能量等于**复振幅的模平方（$|z|^2 = z \cdot z^* = \text{实部}^2 + \text{虚部}^2$）**！

只要你一取模平方，虚数单位 $i$ 就会瞬间消失，变成纯粹的实数加法！
比如在垂直入射（$\theta_i = 0^\circ$）时，我们把复数 $\tilde{n} = n + i\kappa$ 代入 $F_0$ 的复数定义式：
$$ F_0 = \left| \frac{\tilde{n} - 1}{\tilde{n} + 1} \right|^2 = \left| \frac{(n - 1) + i\kappa}{(n + 1) + i\kappa} \right|^2 $$
因为复数商的模等于模的商，且 $|a + ib|^2 = a^2 + b^2$，直接一行算出：
**$$ F_0 = \frac{(n - 1)^2 + \kappa^2}{(n + 1)^2 + \kappa^2} $$**

**看清楚了吗？！**
不管金属的消光系数 $\kappa$ 有多复杂，一旦算出了 $0^\circ$ 时的能量反射率 $F_0$，**虚数 $i$ 就已经被彻底消灭了！算出来的 $F_0$ 是一个实实在在的、介于 $[0, 1]$ 之间的实数！**

如果在红（R = 650nm）、绿（G = 550nm）、蓝（B = 450nm）三个波长上分别代入黄金的 $(n, \kappa)$：
*   红光通道算出来一个实数：$F_{0,R} \approx 1.00$
*   绿光通道算出来一个实数：$F_{0,G} \approx 0.76$
*   蓝光通道算出来一个实数：$F_{0,B} \approx 0.33$

这三个实数组合在一起，不就是美术在贴图里画的那个金黄色的 **`BaseColor = float3(1.00, 0.76, 0.33)`** 吗？！

---

#### 第二层：Schlick 的“偷家”逻辑（两点插值无视中间过程）

现在你明白了：
1. 在 $\theta_i = 0^\circ$（正视）时，金属复杂的复数运算 $(n, \kappa)$ 已经被预先算好（或者由美术直接测量/绘制），浓缩成了三个实数通道 **`F0 = BaseColor`**。
2. 在 $\theta_i = 90^\circ$（掠射角）时，哪怕是复折射率金属，当 $\cos\theta_i = 0$ 代入精确复数菲涅尔方程时：
   $$ R_s(90^\circ) = \left| \frac{0 - \tilde{n}\cos\theta_t}{0 + \tilde{n}\cos\theta_t} \right|^2 = |-1|^2 = \mathbf{1.0} $$
   **金属在 $90^\circ$ 掠射角时的反射率，也依然是绝对的实数 $1.0$（纯白）！**

**Schlick 的天才之处就在于：**
“我根本不管你中间是因为实数折射率 $n$ 产生的曲线，还是因为复数折射率 $n + i\kappa$ 产生的曲线！
反正你们在 $0^\circ$ 时都是一个已知的实数 RGB 向量 **$F_0$**，在 $90^\circ$ 时都必须跑到实数 **$1.0$**！
那我就直接用实数插值公式 $F_0 + (1 - F_0)(1 - \mathbf{V}\cdot\mathbf{H})^5$，把这两个实数端点硬连起来！”

这样一来，Shader 根本不需要知道 $n$ 和 $\kappa$ 是多少，直接拿 `BaseColor` 当作算好的 $F_0$ 起点，用 5 次方一路插值到 1.0，就把金属给渲染出来了！

---

#### 第三层：复数留下的“破绽”（为什么后来需要 F82-Tint？）

用实数 $F_0$ 可以完美代替两个参数 $(n, \kappa)$ 吗？
**在 $0^\circ$ 时可以，但在 $75^\circ \sim 85^\circ$ 时露馅了！**

因为二元复数 $(n, \kappa)$ 有**两个自由度**，而实数 $F_0$ 只有**一个自由度**！
有很多种不同的 $(n, \kappa)$ 组合，算出来的 $0^\circ$ $F_0$ 是完全一样的；但是，**$\kappa$ 比较小、$n$ 比较大的金属（比如铝、铬、铁）**，在 $82^\circ$ 左右（拟布儒斯特角）时，复数分母的实部和虚部相互作用，会导致反射率不但不往 1.0 涨，反而**先往下跌出一个深坑（Fresnel Dip）**！

标准 Schlick 只有一个输入 $F_0$，它是单调递增的，所以它掩盖了这个复数带来的“82度深坑”。
这也完美衔接了我们接下来要讲的 **OpenPBR**：为什么现代标准要在 $F_0$ 之外，再引入一个 $82^\circ$ 的实数颜色参数 **`F82`（第二个自由度）**——就是为了用两个实数参数 $(F_0, F_{82})$，去完整还原复数 $(n, \kappa)$ 的两个自由度！
