我们一步一步用初中代数把这个公式推导出来！

### 一、 金属的痛点：物理学家与美术师的“跨服聊天”

在麦克斯韦电磁学中，要画出一条金属真实的菲涅尔反射曲线（包含 $82^\circ$ 附近的拟布儒斯特角暗带凹陷），你必须知道金属的**复折射率 $\tilde{n} = n + ik$**：
*   实部 $n \in (0, +\infty)$：折射率；
*   虚部 $k \in (0, +\infty)$：消光系数（吸收率）。

**但是，直接让美术去填 $(n, k)$ 是一场灾难！**
1. **数值范围无界**：$n$ 和 $k$ 可以是 $0.1$，也可以是 $8.0$，根本不是 $[0, 1]$ 的颜色，没法画成普通贴图。
2. **严重违反人类直觉**：比如黄金（Gold），它在红、绿、蓝三个波长的实部 $n$ 分别是 $(0.18, \ 0.42, \ 1.37)$。**黄金明明是黄色的（红绿强、蓝弱），但它的折射率实部 $n$ 却是蓝色最大、红色最小！** 美术如果去拉 $n$ 的滑杆，调出来的颜色跟他的直觉完全是反的！

2014 年，フレームストア（Framestore）的图形学者 **Ole Gulbrandsen** 在 JCGT 发表了名作《*Artist Friendly Metallic Fresnel*》。
他提出了一个绝妙的数学问题：
> **“能不能让美术只输入两个符合直觉的 $[0, 1]$ RGB 颜色——正视颜色 $r$（即 $0^\circ$ 的 $F_0$，`base_color`）和 边缘偏色 $g$（`edge_tint`），然后我们在 Shader 内部用严格的代数公式，把 $(r, g)$ 逆向反解回物理上的 $(n, k)$，最后再塞进麦克斯韦方程里？！”**

---

### 二、 第一步数学魔法：$0^\circ$ 反射率 $r$ 在 $(n, k)$ 平面上画出了一个“半圆”！

我们在前面复习过，当光线垂直射向金属表面（$\theta_i = 0^\circ$）时，精确的复数菲涅尔公式为：
**$$ r = \frac{(n - 1)^2 + k^2}{(n + 1)^2 + k^2} $$**
*(这里的 $r \in [0, 1)$ 就是美术画的 `base_color`)*。

请仔细看这个方程：
美术已经给定了 $r$（已知数），但方程里有两个未知数：**$n$ 和 $k$**！
**一个方程解不出两个未知数，但这个方程把 $n$ 和 $k$ 死死绑定在了一条几何曲线上！**

我们把这个方程展开，看看 $(n, k)$ 到底满足什么几何关系：
1. 把分母乘过去：
   $$ r \left[ (n + 1)^2 + k^2 \right] = (n - 1)^2 + k^2 $$
2. 把含 $k^2$ 的项移到一边，含 $n$ 的项留在另一边，直接解出 **$k^2$ 关于 $n$ 和 $r$ 的精确表达式**：
   $$ (1 - r) k^2 = (n + 1)^2 r - (n - 1)^2 $$
   **$$ k^2 = \frac{(n + 1)^2 r - (n - 1)^2}{1 - r} $$**
   *(看！这就是我上一局代码里写的那行 `k2 = ((n + 1)*(n + 1)*r - (n - 1)*(n - 1)) / (1 - r)` 的唯一来源！只要知道了 $r$ 和 $n$，$k^2$ 就瞬间算出来了！)*

3. **更进一步，如果我们对上面的式子关于 $n$ 进行配方（Completing the Square）：**
   $$ \left( n - \frac{1 + r}{1 - r} \right)^2 + k^2 = \left( \frac{2\sqrt{r}}{1 - r} \right)^2 $$

**🚨 见证奇迹的几何画面：**
在以 $n$ 为横轴、$k$（$k \ge 0$）为纵轴的二维平面上，上面这个方程是一个**标准的半圆**！
*   这意味着：**所有能在正面 $0^\circ$ 产生相同颜色 $r$ 的 $(n, k)$ 组合，全都落在这个半圆弧上！**
*   既然锁死在了一个半圆弧上，原本两个未知数 $(n, k)$ 就只剩下了 **1 个自由度**（沿着半圆弧滑动的位置）！

---

### 三、 第二步数学魔法：用边缘参数 $g$ (`edge_tint`) 确定 $n$ 的位置！

现在，我们只需要确定横坐标 $n$ 在这个半圆的底座直径上取哪个值，纵坐标 $k^2$ 就会自动跟着确定！

那么，对于给定的正面反射率 $r$，横坐标 $n$ 的合法取值范围 $[n_{\text{min}}, \ n_{\text{max}}]$ 是多少呢？

1. **右边界 $n_{\text{max}}$（对应半圆最右端，$k^2 = 0$）**：
   令上面公式的分子 $(n + 1)^2 r - (n - 1)^2 = 0$，即 $\sqrt{r}(n + 1) = n - 1$（取 $n > 1$ 的根），直接解出 $n$ 的最大可能值：
   **$$ n_{\text{max}} = \frac{1 + \sqrt{r}}{1 - \sqrt{r}} $$**
   *物理表现*：当 $n$ 取到接近 $n_{\text{max}}$ 时，$n$ 很大而 $k$ 很小，金属在 $82^\circ$ 掠射角附近会产生**最深、最暗的拟布儒斯特角凹陷（Fresnel Dip 最剧烈）**！

2. **左边界 $n_{\text{min}}$（对应半圆偏左端，$n$ 小而 $k$ 大）**：
   理论上左端点是 $\frac{1-\sqrt{r}}{1+\sqrt{r}}$，但 Gulbrandsen 发现如果让 $n < 1$ 且 $k \to 0$，曲线会出现不真实的绝缘体全反射折角。为了保证在 $g \in [0, 1]$ 范围内都是纯正的金属行为，Gulbrandsen 将左边界定义为：
   **$$ n_{\text{min}} = \frac{1 - r}{1 + r} $$**
   *物理表现*：当 $n$ 取到 $n_{\text{min}}$ 时，$n < 1$ 且消光系数 $k$ 很大，金属在掠射角附近几乎没有暗带凹陷，边缘非常明亮饱满！

3. **用美术的 `edge_tint` ($g \in [0, 1]$) 在 $[n_{\text{max}}, n_{\text{min}}]$ 之间做线性插值！**
   Gulbrandsen 让美术输入的第二个颜色参数 $g \in [0, 1]$ 直接作为插值权重：
   **$$ n = g \cdot n_{\text{min}} + (1 - g) \cdot n_{\text{max}} = \text{lerp}(n_{\text{max}}, \ n_{\text{min}}, \ g) $$**

   *   当 $g = 0$ 时：$n = n_{\text{max}}$，金属边缘（$82^\circ$）最暗；
   *   当 $g = 1$ 时：$n = n_{\text{min}}$，金属边缘（$82^\circ$）最亮；
   *   对 R、G、B 三个通道赋予不同的 $g$，就能控制金属在掠射角边缘偏黄、偏红还是偏蓝！

### 四、 第三步数学魔法：把反推出来的 $(n, k^2)$ 代入麦克斯韦导体菲涅尔方程！

现在，我们已经通过美术输入的 $(r, g)$，算出了金属在 R、G、B 三个通道上的物理参数 $n$ 和 $k^2$：
1. $$ n_{\text{min}} = \frac{1 - r}{1 + r}, \qquad n_{\text{max}} = \frac{1 + \sqrt{r}}{1 - \sqrt{r}} $$
2. $$ n = \text{lerp}(n_{\text{max}}, \ n_{\text{min}}, \ g) $$
3. $$ k^2 = \frac{(n + 1)^2 r - (n - 1)^2}{1 - r} $$

最后一步，就是把 $(n, k^2)$ 和入射角余弦 $c = \cos\theta_i = \mathbf{V} \cdot \mathbf{H}$ 代入**麦克斯韦电磁学中的标准导体菲涅尔反射方程**（在金属 $|n + ik|^2 = n^2 + k^2 \gg \sin^2\theta_i$ 条件下的精确解析展开式）：

*   **S 偏振反射率 $R_s$**：
    **$$ R_s(c) = \frac{(n^2 + k^2) - 2 n c + c^2}{(n^2 + k^2) + 2 n c + c^2} $$**
*   **P 偏振反射率 $R_p$**：
    **$$ R_p(c) = \frac{(n^2 + k^2) c^2 - 2 n c + 1}{(n^2 + k^2) c^2 + 2 n c + 1} $$**
*   **总非偏振反射率 $F$**：
    **$$ F(c) = \frac{1}{2} \left( R_s(c) + R_p(c) \right) $$**

**让我们验算一下这个公式的物理美感：**
*   **当正视（$\theta_i = 0^\circ \implies c = 1$）时**：
    $$ R_s(1) = R_p(1) = \frac{n^2 - 2n + 1 + k^2}{n^2 + 2n + 1 + k^2} = \frac{(n - 1)^2 + k^2}{(n + 1)^2 + k^2} \equiv \mathbf{r} \quad (\text{100\% 精确还原输入的 base\_color！}) $$
*   **当掠射角（$\theta_i = 90^\circ \implies c = 0$）时**：
    $$ R_s(0) = \frac{n^2 + k^2}{n^2 + k^2} = 1, \qquad R_p(0) = \frac{1}{1} = 1 \implies F(0) \equiv \mathbf{1.0} \quad (\text{100\% 回归纯白全反射极限！}) $$
*   **当在 $82^\circ$（$c \approx \frac{1}{\sqrt{n^2 + k^2}}$，拟布儒斯特角）附近时**：
    看 $R_p(c)$ 的分子 $(n^2 + k^2)c^2 - 2nc + 1$：当 $c \approx \frac{1}{\sqrt{n^2+k^2}}$ 时，第一项等于 $1$，分子变成了 $2 - \frac{2n}{\sqrt{n^2+k^2}}$，达到**局部极小值**！从而在不用任何 7 次方多项式凑数的情况下，**直接由电磁学偏振方程自动生成了极其真实的 $82^\circ$ 边缘暗带凹陷（Fresnel Dip）**！

### 五、 历史总结：Gulbrandsen (2014/2017) vs F82-Tint (2021/2024)

现在你把 **SPI 2017 的 Gulbrandsen 模型** 和后来 **UE5 / OpenPBR 的 F82-Tint 模型** 对照着看，就会彻底明白这两代金属菲涅尔的演变逻辑：

| 对比维度 | Gulbrandsen 模型 (SPI 2017 / OSL / Arnold 早期) | F82-Tint 模型 (UE5 2022 / OpenPBR 2024) |
| :--- | :--- | :--- |
| **底层数学原理** | **物理反演派**：先用 $(r, g)$ 在半圆上反解出复折射率 $(n, k^2)$，再代入麦克斯韦 $R_s, R_p$ 分式方程。 | **多项式直接拟合派**：彻底跳过 $(n, k)$，直接在 Schlick 5 次方上减去一个 $u(1-u)^6$ 的 7 次方波谷。 |
| **第二个参数的物理意义** | `edge_tint` ($g$) 是 $n$ 在 $[n_{\text{max}}, n_{\text{min}}]$ 之间的插值权重（与最终亮度的关系是非线性的）。 | `T82` 直接就是 $82^\circ$ 处反射率的线性乘法比例（美术所见即所得，调 $0.8$ 就是压暗到 $80\%$）。 |
| **计算开销 (ALU)** | 较高（需计算 $\sqrt{r}$ 以及 4 次三维向量除法求 $n, k^2, R_s, R_p$）。 | **极低**（无开方、无除法，纯乘法与 FMA 指令）。 |

**一句话总结：**
SPI 2017 采用的 Gulbrandsen 公式，是人类第一次成功用两个 $[0, 1]$ 的美术颜色参数完美驾驭麦克斯韦复数导体方程的里程碑；而后来的 F82-Tint，则是为了省去反解 $(n, k)$ 的那四次除法并让边缘调色更线性，在 Gulbrandsen 的启发下进化出的终极多项式替代品！

这个从“半圆反解 $(n, k)$”到“代入 $R_s, R_p$”的数学原理，是不是清晰又巧妙？!]
