

作为Unity游戏开发工程师，我们可以从**原理**、**实现方式**、**优缺点**以及**在Unity中的应用**这几个主要维度来理解**视差贴图 (Parallax Mapping)**。

### 1. 简单定义
视差贴图是一种**着色器（Shader）技术**，旨在不增加模型顶点数量（即不改变几何体形状）的前提下，通过欺骗人眼，让平坦的模型表面表现出强烈的凹凸感和立体深度。

简单来说：**法线贴图（Normal Map）骗过了光照，而视差贴图骗过了视角。**

### 2. 核心原理
它的核心逻辑是利用一张**高度图（Height Map）**（有时也叫深度图），根据观察者的视角（View Direction），动态地**偏移纹理坐标（UV）**。

*   **法线贴图的做法**：改变该像素点的法线方向，让光照计算认为这里有斜坡，从而产生明暗变化。
*   **视差贴图的做法**：当你斜着看地面上的一块凹陷时，你不应该看到凹陷“正上方”的纹理，而应该看到凹陷“侧壁”或“底部偏移”位置的纹理。视差贴图通过算法计算出视线与高度图的交点，然后偏移采样的UV坐标，显示出“正确深处”的像素。

### 3. 技术进阶（从简单到复杂）

视差贴图并非一种单一的算法，而是一类算法的统称，根据消耗和效果分为几个层级：

1.  **简单视差贴图 (Simple Parallax / Offset Mapping)**
    *   **原理**：只进行一次采样。根据视线切线空间的向量和当前高度，做一个简单的UV偏移。
    *   **优点**：极快。
    *   **缺点**：只能处理很浅的凹凸，角度过大时会出现明显的贴图“游泳”或失真现象。

2.  **陡峭视差贴图 (Steep Parallax Mapping)**
    *   **原理**：引入**Raymarching（光线步进）**。将深度分为若干层，沿着视线方向一步步检测视线是否穿过了高度图的表面。
    *   **优点**：深度感更准确。
    *   **缺点**：分层明显，会有“千层饼”一样的锯齿感。

3.  **视差遮蔽贴图 (Parallax Occlusion Mapping - POM)** —— **目前的主流标准**
    *   **原理**：在Steep Parallax的基础上，当检测到视线穿过表面后，在最后两层之间进行**线性插值**，找到精确的交点。同时可以计算软阴影（Self-Shadowing）。
    *   **优点**：效果极佳，甚至能看到砖块之间的遮挡关系。
    *   **缺点**：Pixel Shader计算量大，移动端慎用。

### 4. 与其他技术的对比

| 技术 | 改变了几何体? | 计算成本 | 效果 | 缺陷 |
| :--- | :--- | :--- | :--- | :--- |
| **法线贴图 (Normal)** | 否 | 低 | 表面有纹理细节 | 侧看是平的，没有遮挡感 |
| **视差贴图 (Parallax)** | 否 | 中/高 (取决于POM) | 表面有深度，有遮挡感 | **边缘轮廓依然是平的** |
| **置换贴图 (Displacement / Tessellation)** | **是** | 极高 (由于曲面细分) | 真实的几何凹凸 | 顶点数爆炸，性能消耗极大 |

### 5. 在Unity中的应用

#### A. 必要资源
你需要一张**高度图 (Height Map)**。
*   通常它是灰度图：白色代表凸起（最高点），黑色代表凹陷（最低点）。
*   在Unity的标准流程中，高度图通常被通道打包（Channel Packing），例如放在**Mask贴图的G通道或Blue通道**，或者是法线贴图的Alpha通道（HDRP中常见）。

#### B. 开启方式
*   **Built-in Render Pipeline (标准管线)**:
    *   使用 `Standard` Shader。
    *   在材质球面板中找到 `Height Map` 插槽。
    *   即插即用，通过滑动条调整深度范围。
*   **URP / HDRP**:
    *   在 `Lit` Shader 中寻找 `Height` 或 `Displacement` 选项。
    *   HDRP的高级材质通常支持完整的 **Pixel Displacement (POM)**，可以开启Pixel Depth Offset来处理与其他物体的穿插。

#### C. Shader代码实现思路 (HLSL片段)
如果你自己写Shader，核心逻辑大致如下（简化版）：

```hlsl
// 计算切线空间下的视线方向
float3 viewDirTS = ...; 

// 确定步进次数
const float minLayers = 8;
const float maxLayers = 32;
float numLayers = lerp(maxLayers, minLayers, abs(dot(float3(0, 0, 1), viewDirTS)));

// 每一步的深度增量
float layerDepth = 1.0 / numLayers;
float currentLayerDepth = 0.0;

// UV偏移的增量
float2 P = viewDirTS.xy * _ParallaxScale; 
float2 deltaTexCoords = P / numLayers;

float2 currentTexCoords = i.uv;
float currentDepthMapValue = tex2D(_HeightMap, currentTexCoords).r;

// Raymarching 循环
while(currentLayerDepth < currentDepthMapValue)
{
    // 将UV坐标沿着视线方向偏移
    currentTexCoords -= deltaTexCoords;
    // 获取当前偏移后的高度
    currentDepthMapValue = tex2D(_HeightMap, currentTexCoords).r;
    // 增加当前光线深度
    currentLayerDepth += layerDepth;
}

// ...后续进行插值计算得到最终UV (finalUV) ...

// 使用最终偏移后的UV采样颜色和法线
fixed4 c = tex2D(_MainTex, finalUV);
fixed3 n = UnpackNormal(tex2D(_BumpMap, finalUV));
```

### 6. 开发建议
1.  **性能权衡**：POM非常消耗GPU（主要是纹理采样次数多），在移动端项目中通常只使用最简单的视差映射，或者干脆只用法线贴图。
2.  **边缘穿帮**：视差贴图最大的破绽在于物体的**剪影（Silhouette）**。如果你看一个球体的边缘，虽然中间看起来坑坑洼洼，但球的轮廓依然是完美的圆形。如果非常在意轮廓，需要考虑使用曲面细分（Tessellation）。
3.  **主要用途**：最适合用于**砖墙、鹅卵石路面、瓦片屋顶、格栅地板**等纹理重复且有明显凹凸感的平面物体。
