### 🤯 数学魔法：如何消灭 `min` 和 `max`？

看看你原来的代码，为了求一个轴上的出入点，你算了两个面，然后比较大小：
```hlsl
t1 = (min - ori) * inv_dir;
t2 = (max - ori) * inv_dir;
t_in = min(t1, t2);  // 极其浪费的比较
t_out = max(t1, t2); // 极其浪费的比较
```

**【绝对值定理降维打击】**：
我们不看 `min` 和 `max` 面，我们看这个盒子的**中心点 (Center)** 和**半径扩展 (Extent)**。
*   你的盒子范围是 `X:[-1, 1], Y:[0, 1], Z:[-1, 1]`。
*   它的**中心点 (Center)** 是 `(0, 0.5, 0)`。
*   它的**半径/延展 (Extent)** 是 `(1.0, 0.5, 1.0)`。

如果你把射线起点平移到中心点，射线的计算瞬间变成了对称的。
此时，无论光线是从正面穿过还是反面穿过，**它在这个轴上的“穿透距离”绝对等于 `Extent * abs(inv_dir)`（取绝对值保证永远是正的穿透距离）！**

于是，入口和出口在数学上被绝对锁死：
*   **入口 `t_in` 永远 = 中心相交点 - 穿透距离**
*   **出口 `t_out` 永远 = 中心相交点 + 穿透距离**

没有任何悬念，没有任何 `min/max` 的分支比较！

### 💻 终极极速 AABB 代码

请把你的 Frag 里的 AABB 部分（从 `float3 box_min` 开始，到算 `t_near` 之前）替换成这几行神级代码：

```hlsl
// =================================================================
// 🚀 终极极速 AABB (Center-Extent Absolute Method)
// =================================================================
float3 inv_ray_dir_os = 1.0f / (ray_dir_os + 1e-5f);

// 提取 GPU 的免费指令 Modifier：abs() 
// 在现代 GPU 上，读取寄存器时顺便取绝对值是完全 0 时钟开销的！
float3 abs_inv_dir = abs(inv_ray_dir_os);

// 1. 计算射线穿过 AABB 中心的距离
// 中心点 C = (0.0, 0.5, 0.0)
float3 t_center = (float3(0.0f, 0.5f, 0.0f) - i.ray_ori_os) * inv_ray_dir_os;

// 2. 计算射线在各个轴上的半延展穿透距离
// 半延展 Extent = (1.0, 0.5, 1.0)
float3 t_extent = float3(1.0f, 0.5f, 1.0f) * abs_inv_dir;

// 3. 绝对的数学碾压：不需要 min(t1, t2)，直接得出入口和出口！
float3 t_in  = t_center - t_extent;
float3 t_out = t_center + t_extent;

// 4. 合并各个轴的最大入口和最小出口
float t_near = max(0.0f, max(t_in.x, max(t_in.y, t_in.z)));  
float t_far  = min(t_out.x, min(t_out.y, t_out.z));  

// 【极其重要】：你上次代码里这里有个 return 0，我之前写成了 half4(0,0,0,1)
// 请务必确认这里返回的是透明！否则屏幕上会有黑块/红块
if (t_near >= t_far) return 0.0h;  
```

### 🏆 为什么它在 GPU 上快得不讲道理？

1.  **干掉了 2 条 Vector 比较指令**：原本的 `min(t1, t2)` 和 `max(t1, t2)` 需要调用 GPU 的比较器电路。现在全部换成了极其无脑的减法和加法（`-` 和 `+`）。
2.  **白嫖了 `abs()`**：在大部分 GPU（包括移动端 Mali / Adreno 架构）底层，所有的数字在存入寄存器时都有一个符号位。调用 `abs()` 根本不需要计算，硬件直接在读取时“忽略”那个符号位，所以这行指令的耗时等于 **0**！
3.  **完美触发 FMA（融合乘加）**：`t_center` 的计算 `(C - O) * InvD` 会被编译器直接优化成一条底层的极速 FMA 指令。
