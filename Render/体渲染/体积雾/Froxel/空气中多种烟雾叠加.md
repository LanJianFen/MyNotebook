

这是一个非常硬核且极具现实意义的问题！

在真实的大自然（或者 3A 游戏的渲染）中，空间中的同一点往往是“一锅乱炖”。比如在沙尘暴过后的早晨，空气中既有**沙尘（Dust）**，又有**水滴（Water/Fog）**，甚至还有最基础的**空气分子（Air/Rayleigh）**。

面对这种“混合介质”，许多初学者会想当然地去混合参数（比如把两者的 $g$ 值取个平均）。但在严谨的纯数学和物理世界里，**绝对不能直接混合 $g$ 值**！

大自然有一套极其优美、严格基于**概率论**的混合法则。我们用数学推导一步一步解开它。

---

### 第一步：消光与散射的混合 —— “概率的纯加法”

当一根光线飞入一个混合了“沙尘”和“水雾”的微元 $X_t$ 时，光线撞到粒子的概率是多少？

在微观物理中，沙尘分子和水分子是各自独立存在的。光线撞上任何一个，都会发生散射或吸收。根据概率论中的“互斥事件求和法则”，**系数是可以直接相加的**！

*   **总散射系数：** $\sigma_{s\_total} = \sigma_{s\_dust} + \sigma_{s\_water}$
*   **总消光系数：** $\sigma_{t\_total} = \sigma_{t\_dust} + \sigma_{t\_water}$

物理直觉非常简单：这就好比房间里原本有 10 个红气球（挡住了 10% 的光），你又塞进去 20 个蓝气球（挡住了 20% 的光）。现在房间里挡光的总概率就是 $10\% + 20\% = 30\%$。

**透射率 $T$ 的表现：**
既然 $\sigma_t$ 是相加的，那么透射率 $T$ 呢？
$$ T_{total} = e^{-\int (\sigma_{t\_dust} + \sigma_{t\_water}) dt} $$
根据指数拆分原则 $e^{A+B} = e^A \times e^B$：
$$ T_{total} = e^{-\int \sigma_{t\_dust} dt} \times e^{-\int \sigma_{t\_water} dt} = T_{dust} \times T_{water} $$
这说明：**总的透射率，等于穿过沙尘的透射率，乘以穿过水雾的透射率。** 完美符合物理常识！

---

### 第二步：相位函数的混合 —— “到底听谁的？”

这是最复杂的部分。
沙尘的相函数是 $P_{dust}(\theta)$ （比如 $g=0.3$，向四周散射比较均匀）。
水雾的相函数是 $P_{water}(\theta)$（比如 $g=0.8$，强烈向前散射）。

如果光在这个混合微元 $X_t$ 处发生了散射，**光到底该以什么形状散开呢？**
不能生硬地取 $g = 0.55$，因为 $P(\theta, 0.55)$ 画出来的曲线，和真正的“沙尘+水雾混合曲线”完全是两个形状！

大自然的法则是：**谁的散射能力（$\sigma_s$）强，光就更偏向谁的形状。**
数学上，这叫作**以散射系数为权重的加权平均**：

$$ P_{mix}(\theta) = \frac{\sigma_{s\_dust}}{\sigma_{s\_total}} P_{dust}(\theta) + \frac{\sigma_{s\_water}}{\sigma_{s\_total}} P_{water}(\theta) $$

*物理学解释：* $\frac{\sigma_{s\_dust}}{\sigma_{s\_total}}$ 的含义是“如果光在这个点发生了散射，那么**是被沙尘撞散的概率**”。它被沙尘撞散，当然就按照沙尘的规矩 $P_{dust}$ 来偏折。

---

### 第三步：见证微积分的奇迹时刻（公式坍缩）

现在，我们把求出来的总参数，代回我们之前推导过的 RTE 核心公式（计算微元向相机贡献的光）：

公式本来是这样的：
$$ \text{贡献的光} = \sigma_{s\_total} \cdot \left[ L_{sun} \cdot P_{mix}(\theta) \right] $$

我们把刚才求出来的 $P_{mix}$ 完整代进去，**奇妙的化学反应发生了**：

$$ \text{贡献的光} = \sigma_{s\_total} \cdot L_{sun} \cdot \left[ \frac{\sigma_{s\_dust}}{\sigma_{s\_total}} P_{dust}(\theta) + \frac{\sigma_{s\_water}}{\sigma_{s\_total}} P_{water}(\theta) \right] $$

看到了吗？外面乘的 $\sigma_{s\_total}$，和里面分母上的 $\sigma_{s\_total}$，**完美地约分抵消了！！**

公式瞬间坍缩成了极其干净的形式：
$$ \text{贡献的光} = L_{sun} \cdot \left[ \sigma_{s\_dust} P_{dust}(\theta) + \sigma_{s\_water} P_{water}(\theta) \right] $$

**这是令人起鸡皮疙瘩的数学之美！**
它告诉我们：你根本不需要去计算那个复杂的混合相函数 $P_{mix}$。
在同一个点，沙尘和水雾就像是两个互不干扰的平行宇宙。**你只需要让沙尘自己算自己的发光量，水雾自己算自己的发光量，然后把两者的发光量直接加起来就可以了！**

---

### 第四步：代码层的终极形态

根据上面这个被微积分高度化简的结论，我们在写 Ray Marching 代码时，逻辑变得异常清晰且高效。

```hlsl
// 在循环的内部，当前位置为 Xt

// 1. 分别查出两种材质的各自参数（互不干扰）
float3 sigma_s_dust  = GetDustScattering(Xt);
float3 sigma_t_dust  = GetDustExtinction(Xt);

float3 sigma_s_water = GetWaterScattering(Xt);
float3 sigma_t_water = GetWaterExtinction(Xt);

// 2. 总消光系数直接相加 (用于消耗生命值)
float3 sigma_t_total = sigma_t_dust + sigma_t_water;

// 3. 计算抵达这里的太阳光 (光在飞来的路上，是被总消光挡住的)
float3 sunLightAtXt = ComputeDirectionalLight(Xt, sunDir, sigma_t_total);

// 4. 【奇迹发生的地方】：分别计算它们的内散射，然后直接相加！
float phase_dust  = PhaseFunctionHG(cosTheta, 0.3); // 沙尘的 g=0.3
float phase_water = PhaseFunctionHG(cosTheta, 0.8); // 水滴的 g=0.8

// 分别算出沙尘和水雾弹给相机的光
float3 radiance_dust  = sigma_s_dust  * sunLightAtXt * phase_dust;
float3 radiance_water = sigma_s_water * sunLightAtXt * phase_water;

// 直接相加！
float3 total_step_radiance = radiance_dust + radiance_water;

// 5. 按照标准的 RTE 累加到主背包中
L += T * total_step_radiance * dt;

// 6. 用总消光系数扣除射线的干粮
T *= exp(-sigma_t_total * dt);
```

### 工程师视角的防坑指南

虽然代码写出来很简单，但在工业界，由于初学者不懂上面这段数学推导，常常会犯一个极其愚蠢的错误：**Lerp 谬误**。

有的程序员会这么写（**错误示范**）：
```hlsl
// ❌ 灾难性的错误写法！
float fake_g = lerp(0.3, 0.8, water_ratio); // 强行把 g 值混合
float phase_mix = PhaseFunctionHG(cosTheta, fake_g);
float3 radiance = (sigma_s_dust + sigma_s_water) * sunLight * phase_mix;
```
**为什么错得离谱？**
如果沙尘极浓，水雾极浓。正确的物理结果是：光线既会呈现出水雾的“强烈日晕（高光）”，又会呈现出沙尘的“粗糙侧面反光（底色）”。
但如果你强行把 $g$ 混合成 $0.55$，相函数就变成了一个“既没有高光，也没有底色”的四不像曲线！画出来的雾气会像一坨扁平的泥巴，彻底失去大气的光学细节。

**总结：**
在数学的指引下，处理多材质混合的最优解，就是**保持它们的独立性**。消光（死亡）可以相加，但发光（新生）必须各自计算再汇合。这就是 RTE 对大自然最深刻的还原。
