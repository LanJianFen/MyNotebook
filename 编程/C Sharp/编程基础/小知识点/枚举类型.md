

在 C# 中，**枚举（Enum）本质上是一个强类型的命名整数（默认底层是 `int`）**。

下面针对你的 3 个疑问逐一详细解答：

---

### 一、 C# 的 Enum 怎么进行传参？

因为 Enum 是基本值类型（Value Type），传参方式和传普通的 `int`、`float` 一模一样，直接作为类型声明即可：

#### 1. 基础传参（最常用）：
```csharp
public enum QualityLevel
{
    Low,
    Medium,
    High
}

// 作为形参直接传递
public void SetQuality(QualityLevel level)
{
    Debug.Log("当前设置的画质是：" + level);
}

// 调用
SetQuality(QualityLevel.High);
```

#### 2. 整数与枚举相互强转：
底层是整数，因此可以在 `int` 和 `Enum` 之间自由强转：
```csharp
// int 转 Enum
int savedValue = 2;
QualityLevel level = (QualityLevel)savedValue; // 变为 QualityLevel.High

// Enum 转 int
int intValue = (int)QualityLevel.High; // 变为 2
```

---

### 二、 它拿到的是下标，还是写的“等号（指定值）”？

👉 **严格按照【等号（指定值）】！它根本不是以数组下标（Index）为准的。**

#### 规则解析：
1. **如果不写等号：** 编译器会默认从 `0` 开始递增赋值（0, 1, 2, 3...）。
2. **只要写了等号：** 它底层的真实值**永远是你赋给它的那个数字**。

#### 实例说明：
```csharp
public enum ShaderLODLevel
{
    Low = 100,      // 底层值是 100（不是 0）
    Medium = 200,   // 底层值是 200（不是 1）
    High = 400,     // 底层值是 400（不是 2）
    Ultra           // 没写等号，会自动在上一个基础上 +1，变成 401！
}

void Test(ShaderLODLevel lod)
{
    int value = (int)lod;
    Debug.Log(value); 
}

// 调用：
Test(ShaderLODLevel.Medium); // 👉 打印出来的是 200，绝对不是 1！
```

* **结论：** 传参传递的本质就是传递那个底层的整数值（赋给它的等号值）。

### 三、 怎么把枚举的元素名转换成字符串（String）？

开发中有以下几种常用转换方式：

#### 1. `.ToString()`（最通用，最直观）
```csharp
QualityLevel level = QualityLevel.High;
string name = level.ToString(); 
// 输出: "High"
```

#### 2. `nameof()`（性能最好，0 GC 开销，编译期完成）
如果你在写代码时已经确定了要哪个枚举项的名字：
```csharp
string name = nameof(QualityLevel.High);
// 输出: "High"（编译期直接变成常量字符串，没有任何内存分配）
```

#### 3. `Enum.GetName()`（适合动态获取）
```csharp
string name = Enum.GetName(typeof(QualityLevel), QualityLevel.Medium);
// 输出: "Medium"
```

### 🎁 补充：反向操作 —— 怎么把字符串转回 Enum？

在读配置文件（JSON、XML、网络协议）时经常需要将字符串转成枚举，推荐使用 **`Enum.TryParse`**（安全防报错）：

```csharp
string inputStr = "High";

// true 表示忽略大小写（比如 "high" 也能成功识别）
if (Enum.TryParse<QualityLevel>(inputStr, true, out QualityLevel result))
{
    Debug.Log("转换成功：" + result); // QualityLevel.High
}
else
{
    Debug.LogError("字符串不匹配任何枚举项！");
}
```
