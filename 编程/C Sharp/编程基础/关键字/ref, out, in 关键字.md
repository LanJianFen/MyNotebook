`ref`、`out` 和 `in` 是 C# 中用于指定参数**按引用传递（Pass by Reference）**的三个关键字。它们的共同点是避免了值类型（如 `struct`、基本数据类型）在传参时的内存拷贝，但在**初始化要求**、**只读/可写限制**和**设计用途**上有明确分工：

### 三者核心对比

理解它们和 **`struct`（值类型）** 及 **`class`（引用类型）** 结合的使用规则，是掌握 C# 内存优化与底层机制的关键。

核心差异一句话概括：

> - **`struct` 结合：** 控制的是**整个数据结构本身**是否需要发生**字节拷贝**。
> - **`class` 结合：** 控制的是**指向对象的“引用（指针）”本身**能否被重新赋值。


### 一、 与 `struct`（值类型）结合

结构体在默认情况下是**按值传递**的（在栈上逐字节复制）。

#### 1. 默认情况（无修饰符）
- **规则**：将整个结构体在内存中**完整复制**一份传给函数。
- **作用与开销**：如果结构体很大（比如 Unity 的 `RenderingData` 包含几百个字节），频繁按值传递会带来显著的**栈内存拷贝开销**。

#### 2. `ref struct`
- **规则**：传递结构体在内存中的真实地址。函数内部修改结构体的字段，**会直接修改外部原变量**。
- **主要作用**：
    1. **零拷贝开销**：传递 8 字节的内存指针，而不是几百字节的数据。
    2. **双向状态同步**：用于需要直接修改传入结构体内容的函数（如修改向量 `Vector3` 的坐标）。
    
```
void OffsetPoint(ref Vector3 pos)
{
    pos.x += 10.0f; // 直接修改外部的 pos
}
```

#### 3. `in struct`（图形渲染/高性能开发中最常用）
- **规则**：传递内存地址（零拷贝），但**编译器禁止在函数内修改结构体的任何字段**。
- **主要作用**：**性能优化 + 状态安全**。
    - 当你只希望**读取**一个大型结构体（如 `RenderingData`），又不希望产生任何拷贝开销时使用。

```
void ReadData(in RenderingData data)
{
    // float aspect = data.cameraData.aspectRatio; // 正确：读取数据，零拷贝
    // data.cameraData = ...;                      // 编译报错！in 参数禁止修改
}
```

> 💡 **防御性拷贝提示**：如果 `struct` 内部包含非 `readonly` 方法，使用 `in` 调用这些方法时编译器会产生隐藏的“防御性拷贝”。因此，配合 `readonly struct` 或 `readonly` 方法使用 `in` 性能最高。

#### 4. `out struct`
- **规则**：传入前不需要初始化结构体，函数内部**必须**对结构体的所有字段（或整个结构体）进行初始化。
- **主要作用**：避免传入无意义的旧数据，纯粹用于填充并输出一个新的结构体（如 `Physics.Raycast` 输出 `RaycastHit`）。
### 二、 与 `class`（引用类型）结合
类在默认情况下传参时，传递的是**指针的副本**（Pass By Value of Reference）。

#### 1. 默认情况（无修饰符）
- **规则**：复制一份指向对象的指针。
    - 函数内**修改对象的属性**（如 `obj.Name = "A"`）$\rightarrow$ **外部有效**（因为指向同一个堆对象）。
    - 函数内**将变量重新赋值**（如 `obj = new MyClass()`）$\rightarrow$ **外部无效**（只是断开了指针副本的指向）。
#### 2. `ref class`
- **规则**：传递**指针本身的引用**（相当于 C++ 中的二级指针 `MyClass**`）。
- **主要作用**：允许在函数内部**替换外部变量所指向的对象实例**。
```
void ReplaceTexture(ref Texture2D tex)
{
    // 不仅能改属性，还能直接替换外部变量指向的新对象！
    tex = new Texture2D(512, 512); 
}

// 使用
Texture2D myTex = oldTex;
ReplaceTexture(ref myTex);
// 现在 myTex 已经指向了 new Texture2D(512, 512)
```
#### 3. `in class`
- **规则**：可以修改对象的属性，但**禁止在函数内把变量重新赋值指向新对象**。
- **主要作用**：保证引用的“指向不变性”（Identity Consistency）。
```
void ProcessMaterial(in Material mat)
{
    mat.color = Color.red;       // 可以！对象内部的属性依然可以修改
    // mat = new Material(...);  // 编译报错！in 禁止重新给 mat 赋值新引用
}
```

#### 4. `out class`
- **规则**：传入前变量可以为 `null`，函数内部**必须**实例化并给该变量赋值（或赋 `null`）。
- **主要作用**：工厂模式或异步加载时，由函数内部创建对象并吐出给外部。
```
bool TryLoadMaterial(string path, out Material mat)
{
    mat = Resources.Load<Material>(path); // 必须给 mat 赋值
    return mat != null;
}
```

### 三、 总结对比表

|**组合方式**|**对 struct 的作用**|**对 class 的作用**|
|---|---|---|
|**默认（无）**|拷贝整个数据（有内存开销）|拷贝指针（可改属性，不可改外部指针指向）|
|**`ref`**|传地址，**可修改**原数据（0 拷贝）|传指针地址，**可修改**原变量指向的新对象|
|**`in`**|传地址，**只读**原数据（0 拷贝，最高效）|传指针地址，**只读指针**（但可修改对象内部属性）|
|**`out`**|传地址，**必须初始化**结构体|传指针地址，**必须实例化/赋值**对象|
