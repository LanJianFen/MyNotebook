

对于 Unity 工程师来说，**LUT (Look-Up Table)** 可以理解为**“颜色的作弊小抄”**。

在图形学中，全称是 **颜色查找表**。它是后处理（Post-processing）中实现**滤镜（Color Grading / 调色）**最核心、最高效的技术手段。

---

### 1. 通俗原理：查表法

假设你有一张图片，你需要对它进行复杂的调色（比如：把红色变暗点，把蓝色偏向青色，增加对比度）。

*   **没有 LUT 的做法（纯数学）：**
    GPU 需要针对每个像素跑一堆公式：
    `NewColor = (OldColor * Contrast) + (OldColor.r * 0.5) ...`
    公式越复杂，Shader 越昂贵。

*   **有 LUT 的做法（查表）：**
    我们预先算好所有颜色的变化结果，存成一张特殊的纹理（LUT 图）。
    当 GPU 渲染时，它拿起一个像素的颜色（比如 RGB = 0.5, 0.2, 0.1），它不进行计算，而是直接去 LUT 纹理的 `(0.5, 0.2, 0.1)` 这个坐标位置看一眼：**“喂，这个原本的颜色应该变成什么？”**
    LUT 回答：“变成 (0.4, 0.2, 0.15)”。
    
**核心优势：** 无论美术师在 Photoshop 里叠了多少层曲线、色阶、黑白调整，到了 Unity 里，**性能消耗永远是一次纹理采样（Texture Sample）。**

---

### 2. Unity 中的 LUT 长什么样？

在 Unity 的 Post-processing 或 URP/HDRP Volume 中，你会看到 **Color Lookup** 选项。

常用的 LUT 是一张 **2D 纹理**，通常看起来是一条长长的渐变色带，或者方块阵列。
*   **本质：** 它其实是一个 **3D 颜色立方体**（RGB 三个轴）。
*   **存储：** 因为图片是 2D 的，所以我们将这个 3D 立方体切成片（Slices），平铺在 2D 图片上。

最常见的规格是 **32x32x32**（即精度为 32），对应的贴图大小通常是 **1024x32**（32个切片平铺）。

---

### 3. Unity 工程师必知的制作流

1.  **截帧：** 去 Unity 运行游戏，截一张没开特效的图（Game View 截图）。
2.  **PS 调色：** 把截图丢进 Photoshop。美术师在上面加“曲线”、“色彩平衡”等各种调整图层，直到画面好看为止。
3.  **应用到 LUT：** 保持调整图层不动，把**基准 LUT图（Neutral LUT，一般是一张标准的彩虹色方块图）** 拖进 PS，放在截图同一个位置。
4.  **导出：** 之前的调整图层会自动作用在这个基准 LUT 上。把你调好的这个 LUT 裁剪出来存成 PNG。
5.  **导入 Unity：** 赋值给 Post Process Volume。

### 4. 这里的“坑”和注意事项（技术重点）

作为工程师，你经常要处理美术导进来的 LUT 效果不对的问题，通常是以下原因：

#### A. 导入设置 (Import Settings) - **最容易错！**
LUT 是一张**数据图**，不是用来给人看的图片。所以导入设置必须极其严格：
*   **sRGB (Color Texture):** **必须取消勾选！** LUT 存储的是线性数学关系，不能被 Gamma 校正干扰。
*   **Filter Mode:** 建议 **Bilinear**（双线性过滤）或 Trilinear，如果在两个颜色之间，我们需要平滑过渡，不能用 Point（否则颜色会有断层）。
*   **Compression:** 最好选 **None (不压缩) 也就是 RGBA32**。任何压缩（DXT/ETC）都会导致颜色出现极丑的色斑（Artifacts），尤其是在暗部。
*   **Wrap Mode:** **Clamp**。防止采样越界读到对面的颜色。

#### B. 精度问题 (Color Banding)
常见的 LUT 尺寸是 16x16x16 (256x16 px) 或 32x32x32 (1024x32 px)。
*   如果是 16 的精度，颜色过渡可能会出现**波纹/断层 (Banding)**，尤其是天空这种平滑渐变区域。
*   建议移动端用 32 精度，主机/PC 可以更高，但 32 通常够用了。

#### C. 不要完全依赖 LUT
LUT 只能做**颜色映射（1对1换色）**。
它做不了：
*   模糊（Blur）、泛光（Bloom）
*   依赖屏幕坐标的效果（比如暗角 Vignette）
*   动态效果

### 总结

**LUT** 是一种**把复杂的调色逻辑“烘焙”成一张纹理**的技术。
对于 Unity 工程师，它的意义在于：**让美术在 Photoshop 里随心所欲，而运行时的性能开销恒定且极低。**
只要记住：**Import Settings 里把 sRGB 关掉，不要压缩！**
